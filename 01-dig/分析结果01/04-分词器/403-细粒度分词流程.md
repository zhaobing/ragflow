# RagTokenizer `fine_grained_tokenize` 方法分析报告

## 一、方法概述

**方法位置**: [infinity/rag_tokenizer.py:433-471](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L433-L471)

**方法签名**:
```python
def fine_grained_tokenize(self, tks: str) -> str:
```

**核心功能**: 对已分词的文本进行**细粒度拆分**，将复合词进一步分解为更小的语义单元，用于**关键词匹配和精确检索**。

## 二、业务逻辑

### 2.1 设计目的

`fine_grained_tokenize` 与 `tokenize` 的区别：

| 特性 | tokenize | fine_grained_tokenize |
|------|----------|----------------------|
| **粒度** | 粗粒度（保留完整词组） | 细粒度（拆分复合词） |
| **用途** | 语义检索 | 关键词匹配 |
| **示例** | "人工智能" | "人工 智能" |
| **目标** | 保留语义完整性 | 提高召回率 |

### 2.2 核心功能

1. **语言类型检测**: 自动识别文本是中文主导还是英文主导
2. **英文特殊处理**: 对英文文本按斜杠 `/` 分割（如 "AI/Machine-Learning"）
3. **中文细粒度拆分**: 将中文复合词拆分为单字或双字词
4. **评分排序**: 使用DFS生成所有可能的分词方案，选择**第二优**方案
5. **英文规范化**: 对英文词进行词干提取和词形还原

### 2.3 在RAGFlow中的应用

从代码搜索结果可见，`fine_grained_tokenize` 主要用于：

```python
# 1. 生成细粒度分词索引 (rag/nlp/__init__.py:273)
d["content_ltks"] = rag_tokenizer.tokenize(text)          # 粗粒度
d["content_sm_ltks"] = rag_tokenizer.fine_grained_tokenize(d["content_ltks"])  # 细粒度

# 2. 文档标题细粒度分词
doc["title_tks"] = rag_tokenizer.tokenize(title)
doc["title_sm_tks"] = rag_tokenizer.fine_grained_tokenize(doc["title_tks"])

# 3. GraphRAG实体提取
chunk["content_sm_ltks"] = rag_tokenizer.fine_grained_tokenize(chunk["content_ltks"])
```

#### 步骤2: 中文细粒度分词 ([line 442-469](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L442-L469))

```python
res = []
for tk in tks:
    # 2.1 跳过短词和数字
    if len(tk) < 3 or re.match(r"[0-9,\.-]+$", tk):
        res.append(tk)
        continue

    # 2.2 DFS生成分词方案
    tkslist = []
    if len(tk) > 10:
        # 超长词：直接保留，不分词
        tkslist.append(tk)
    else:
        # 正常词：DFS生成所有可能的分词方案
        self.dfs_(tk, 0, [], tkslist)

    # 2.3 检查是否需要分词
    if len(tkslist) < 2:
        # 只有1种方案（原词），无需分词
        res.append(tk)
        continue

    # 2.4 选择第二优方案
    stk = self._sort_tokens(tkslist)[1][0]

    # 2.5 处理选择结果
    if len(stk) == len(tk):
        # 分词后长度与原词相同，说明没有真正分词
        stk = tk
    else:
        # 检查是否是纯英文
        if re.match(r"[a-z\.-]+$", tk):
            # 英文词：检查是否有短词
            for t in stk:
                if len(t) < 3:
                    # 有长度<3的词，回退到原词
                    stk = tk
                    break
            else:
                # 没有短词，接受分词结果
                stk = " ".join(stk)
        else:
            # 中文词：接受分词结果
            stk = " ".join(stk)

    res.append(stk)
```

**english_normalize_ 实现** ([line 336-337](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L336-L337)):

```python
def english_normalize_(self, tks):
    return [
        self.stemmer.stem(self.lemmatizer.lemmatize(t))
        if re.match(r"[a-zA-Z_-]+$", t) else t
        for t in tks
    ]
```

**处理流程**:
```python
输入: ["人工", "machine", "智能", "learning"]

英文规范化:
  "人工"     → 不是英文 → "人工"
  "machine"  → lemmatize("machine") → "machine"
            → stem("machine") → "machin"
  "智能"     → 不是英文 → "智能"
  "learning" → lemmatize("learning") → "learning"
            → stem("learning") → "learn"

输出: ["人工", "machin", "智能", "learn"]
```

## 五、技术要点

### 5.1 第二优方案选择策略

**设计原理**:
```python
_sorted_tokens[0]  # 粗粒度方案（词数少，评分高）
_sorted_tokens[1]  # 细粒度方案（词数多，评分中等）✓
_sorted_tokens[2]  # 过度拆分方案（词数过多，评分低）
```

**对比示例**:
```python
输入: "自然语言处理"

DFS生成的评分排序:
[0] ["自然语言处理"] 评分: 35.8  ← tokenize使用
[1] ["自然", "语言", "处理"] 评分: 18.5  ← fine_grained_tokenize使用 ✓
[2] ["自", "然", "语言", "处理"] 评分: 12.3

效果对比:
- tokenize: 保留完整词组 → 语义检索 → 查询"NLP"能匹配
- fine_grained: 拆分为3个词 → 关键词匹配 → 查询"语言"也能匹配
```

### 5.2 英文短词保护机制

```python
if re.match(r"[a-z\.-]+$", tk):
    for t in stk:
        if len(t) < 3:
            stk = tk  # 回退到原词
            break
```

**保护原因**:
- 英文单字母或双字母通常是缩写（AI, IT, PhD）
- 强行拆分会破坏语义
- 中文不受此限制（单字也有语义）

**示例**:
```python
"AI" → ["A", "I"] → 检测到短词 → 回退 → "AI"
"IT" → ["I", "T"] → 检测到短词 → 回退 → "IT"
"人工智能" → ["人工", "智能"] → 中文，无检查 → "人工 智能"
```

### 5.3 超长词保留策略

```python
if len(tk) > 10:
    tkslist.append(tk)  # 直接保留原词，不分词
else:
    self.dfs_(tk, 0, [], tkslist)  # DFS生成分词方案
```

**设计原因**:
- 长度>10的词通常是专有名词、技术术语、URL等
- DFS搜索空间会指数增长
- 强行拆分可能破坏语义

**示例**:
```python
"深度学习神经网络Transformer模型" (len=15)
  → 超长，直接保留
  → 不进行细粒度拆分

"人工智能" (len=4)
  → 正常长度，DFS拆分
  → "人工 智能"
```

### 5.4 数字和符号识别

```python
if re.match(r"[0-9,\.-]+$", tk):
    res.append(tk)  # 直接保留
    continue
```

**匹配模式**:
- `[0-9]`: 数字
- `,`: 千位分隔符（1,000）
- `.`: 小数点或IP地址（192.168.1.1）
- `-`: 日期或电话号码（2024-12-30）

**示例**:
```python
"2024" → 匹配 → "2024"
"12.30" → 匹配 → "12.30"
"1,000" → 匹配 → "1,000"
"192.168.1.1" → 匹配 → "192.168.1.1"
```

## 七、tokenize 与 fine_grained_tokenize 对比

### 7.1 功能对比表

## 八、总结

### 8.1 核心特性

1. **细粒度拆分**: 将复合词拆分为更小的语义单元
2. **第二优方案**: 选择评分第二的分词方案，平衡召回率和精确率
3. **语言自适应**: 自动检测中英文，采用不同的处理策略
4. **智能过滤**: 跳过短词、数字、符号等无意义的拆分
5. **英文保护**: 对英文短词（<3字符）进行保护，避免过度拆分

### 8.2 设计优势

- **高召回率**: 通过拆分复合词，支持部分关键词匹配
- **互补性**: 与 `tokenize` 配合，同时支持精确匹配和模糊匹配
- **智能化**: 根据词长、词性、语言类型自适应处理
- **可控性**: 通过评分机制控制拆分粒度

### 8.3 适用场景

- **关键词检索**: 用户查询部分关键词也能匹配到文档
- **自动补全**: 根据部分输入提示完整词组
- **实体链接**: 将细粒度词链接到知识库实体
- **标签推荐**: 从细粒度词中提取标签和关键词

### 8.4 与 tokenize 的关系

```
tokenize (粗粒度) → fine_grained_tokenize (细粒度)
       ↓                       ↓
  语义检索                 关键词匹配
       ↓                       ↓
  高精确率                 高召回率
       └──────────┬────────────┘
                  ↓
          组合检索策略
        平衡精确率和召回率
```

`fine_grained_tokenize` 是 RAGFlow 实现高召回率检索的关键组件，与 `tokenize` 形成互补的双重索引策略，为用户提供了更智能、更全面的检索体验。
