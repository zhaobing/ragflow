## 1. 整体流程概览

### 1.1 查询执行主链路

```mermaid
sequenceDiagram
    participant User as 用户
    participant API as API层<br/>(conversation_app.py)
    participant Service as 服务层<br/>(dialog_service.py)
    participant Retriever as 检索器<br/>(retriever)
    participant Rerank as 重排序<br/>(rerank_mdl)
    participant LLM as 大模型<br/>(chat_mdl)
    participant ES as ES/Infinity<br/>(doc_store)

    User->>API: POST /completion
    API->>Service: async_chat(dialog, messages)
    Service->>Service: 问题精炼(refine)
    Service->>Service: 多轮融合(full_question)
    Service->>Service: 跨语言处理(cross_languages)
    Service->>Retriever: retrieval(question, embd_mdl)
    Retriever->>ES: 向量检索+关键词检索
    ES-->>Retriever: 候选chunks
    Retriever-->>Service: kbinfos
    Service->>Rerank: rerank(chunks)
    Rerank-->>Service: 排序后的chunks
    Service->>Service: 知识组装(kb_prompt)
    Service->>Service: 插入引用(insert_citations)
    Service->>LLM: async_chat_streamly(prompt)
    LLM-->>Service: 流式答案
    Service-->>API: 流式响应
    API-->>User: SSE流式返回
```

| 阶段 | 关键方法 | 说明 |

**方法**: `async_chat(dialog, messages, stream=True, **kwargs)`

**分析要点**:

- SQL检索模式判断（`use_sql`）
- 问题精炼流程（`refine_multiturn`, `full_question`）

- 深度研究模式（`reasoning` with DeepResearcher）
- 提示词组装（prompt construction）
- LLM调用与流式输出
- 时间统计与性能监控

**核心流程**:
```python
async def async_chat(dialog, messages, stream=True, **kwargs):
    # 1. 模型加载
    kbs, embd_mdl, rerank_mdl, chat_mdl, tts_mdl = get_models(dialog)

    # 2. SQL模式检查
    if field_map:
        ans = await use_sql(...)
        if ans: return

    # 3. 问题精炼
    if refine_multiturn:
        questions = [await full_question(...)]

    # 4. 检索
    kbinfos = retriever.retrieval(...)

    # 5. 知识图谱检索
    if use_kg:
        ck = settings.kg_retriever.retrieval(...)

    # 6. 知识组装
    knowledges = kb_prompt(kbinfos, max_tokens)

    # 7. LLM生成
    async for ans in chat_mdl.async_chat_streamly(...):
        yield ans
```

### 任务4: 知识检索流程

**文件**: [rag/nlp/search.py](../../../rag/nlp/search.py)

**方法**: `retrieval()`, `retrieval_by_toc()`, `retrieval_by_children()`

**分析要点**:
- 混合检索策略（向量+关键词+标量特征）
- 相似度计算（vector_similarity_weight）
- Top-K与Top-N控制
- TOC增强检索（目录结构增强）
- 子chunk检索（retrieval_by_children）
- 检索结果聚合（doc_aggs）

**检索公式**:
```python
final_score = vector_similarity_weight * vector_score +
              (1 - vector_similarity_weight) * keyword_score +
              rank_feature_score
```

**关键参数**:
- `similarity_threshold`: 相似度阈值（默认0.2）
- `vector_similarity_weight`: 向量权重（默认0.3）
- `top_n`: 每个知识库检索数量
- `top_k`: 最终保留数量
