### 步骤 6: 构建词元查询 (query.py:198-215)

```python
# 对同义词进行细粒度分词
tk_syns = [rag_tokenizer.fine_grained_tokenize(s) for s in tk_syns if s]
tk_syns = [f'"{s}"' if s.find(" ") > 0 else s for s in tk_syns]

# 处理原词
tk = FulltextQueryer.sub_special_char(tk)
if tk.find(" ") > 0:
    tk = '"%s"' % tk  # 多词组用引号包裹

# 添加同义词 (低权重 0.2)
if tk_syns:
    tk = f"({tk} OR ({tk_syns})^0.2)"

# 添加细粒度分词 (低权重 0.5, 近似匹配 ~2)
if sm:
    tk = f'{tk} OR "{sm}" OR ("{sm}"~2)^0.5'

if tk.strip():
    tms.append((tk, w))  # (查询表达式, 权重)
```

**Lucene 查询语法**:
```python
tk = "人工智能"
sm = ["人工", "智能"]
tk_syns = ["机器智能"]

构建:
  "人工智能"                    # 精确匹配
  OR ("机器智能")^0.2           # 同义词，权重 0.2
  OR "人工 智能"                # 细粒度分词（短语）
  OR ("人工 智能")~2^0.5        # 近似匹配，间隔2词内

最终:
  "人工智能" OR ("机器智能")^0.2 OR "人工 智能" OR ("人工 智能")~2^0.5
```

### 步骤 7: 组合词元查询 (query.py:217-222)

```python
# 按权重组合所有词元
tms = " ".join([f"({t})^{w}" for t, w in tms])

# 如果有多个词元，添加原术语的近似匹配
if len(twts) > 1:
    tms += ' ("%s"~2)^1.5' % rag_tokenizer.tokenize(tt)
```

**示例**:
```python
twts = [("人工智能", 0.5), ("AI", 0.3)]

tms = "({人工智能})^0.5 ({AI})^0.3"
tms += ' ("人工 智能")~2^1.5'  # 原术语的近似匹配，高权重
```

---

### 步骤 8: 添加术语级同义词 (query.py:224-231)

```python
# 构建术语级同义词查询
syns = " OR ".join([
    '"%s"' % rag_tokenizer.tokenize(FulltextQueryer.sub_special_char(s))
    for s in syns
])

# 组合: 术语查询 (高权重) OR 同义词 (低权重)
if syns and tms:
    tms = f"({tms})^5 OR ({syns})^0.7"

qs.append(tms)
```

**示例**:
```python
术语: "ai"
syns: ["人工智能", "artificial intelligence"]
tms: "({ai})^0.6"

组合:
  (({ai})^0.6)^5 OR ("人工智能" OR "artificial intelligence")^0.7

= ({ai})^3.0 OR ("人工智能" OR "artificial intelligence")^0.7
```

## 查询权重设计总结

| 组件 | 权重 | 说明 |
|-----|------|------|
| **原词元** | `^1.0` | 基准权重 |
| **术语组合** | `^5` | 精确匹配整个术语 |
| **术语同义词** | `^0.7` | 降低同义词权重 |
| **词元同义词** | `^0.2` | 进一步降低权重 |
| **细粒度分词** | `^0.5` | 中等权重 |
| **近似匹配** | `~2` | 允许2词间隔 |
| **近似匹配** | `^1.5` | 词元级近似匹配 |

**权重层次**:
```
术语精确匹配 (×5)
  ↓
词元精确匹配 (×1)
  ↓
细粒度分词 (×0.5)
  ↓
术语同义词 (×0.7)
  ↓
词元同义词 (×0.2)
```

## 关键设计亮点

### 1. 多粒度查询
```
术语级别: "ai" → (ai)^5
词元级别: "artificial" → (artificial)^0.8
字符级别: 近似匹配 ~2
```

### 2. 同义词层次扩展
```
术语同义词: "ai" → "人工智能" (权重 0.7)
词元同义词: "artificial" → "人造" (权重 0.2)
```

### 3. 权重衰减策略
```
精确匹配 > 近似匹配 > 同义词匹配
```

### 4. 数量限制
```python
术语数: 256个
关键词数: 32个
```

---

## 总结

这种设计通过**多层扩展 + 权重衰减**，在保证召回率的同时，通过权重控制精确度，是一种经典的检索查询优化策略。

**核心思想**:
- **多粒度**: 术语 → 词元 → 字符
- **多扩展**: 同义词 → 细粒度分词 → 近似匹配
- **权重控制**: 精确匹配 > 近似匹配 > 同义词匹配

这种策略在信息检索系统中非常常见，能够有效平衡召回率和精确率。
