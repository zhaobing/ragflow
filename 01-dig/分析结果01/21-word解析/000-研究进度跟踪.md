## 核心数据结构

### Chunk完整结构

```python
{
    # ===== 内容相关 =====
    "content_with_weight": str,      # 原始文本内容
    "content_ltks": str,             # 粗粒度分词
    "content_sm_ltks": str,          # 细粒度分词
    "mom_with_weight": str,          # 原始文本（有子分隔符时）

    # ===== 文档元数据 =====
    "docnm_kwd": str,                # 文档名称
    "title_tks": str,                # 标题分词
    "title_sm_tks": str,             # 标题细粒度分词

    # ===== 位置信息 =====
    "page_num_int": List[int],       # 页码列表
    "position_int": List[tuple],     # 位置坐标 (pn, left, right, top, bottom)
    "top_int": List[int],            # 顶部坐标

    # ===== 类型标记 =====
    "doc_type_kwd": str,             # 文档类型: table/image

    # ===== 图片 =====
    "image": PIL.Image,              # 关联图片
}
```

   ```python

   ```

3. **可视化输出**:
   - 保存中间结果 (sections, chunks)
   - 导出图片查看提取效果
   - 查看分词结果

   - 不同chunk_token_num的效果
   - 有无自定义分隔符的差异
   - 图片是否正确关联
