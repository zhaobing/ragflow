# PDF文档图文分离处理机制分析

## 方法概述

_extract_table_figure 方法位于 deepdoc/parser/pdf_parser.py (第868-1040行)，是 RAGFlow PDF 解析器中负责从已布局识别的文本块中提取表格和图片的核心方法。

### 方法签名

```python
def _extract_table_figure(self, need_image, ZM, return_html, need_position, separate_tables_figures=False):
```

**参数说明：**
- need_image: 是否需要提取图片裁剪
- ZM: 缩放倍数（用于裁剪时坐标转换）
- return_html: 表格是否返回 HTML 格式
- need_position: 是否需要返回位置信息
- separate_tables_figures: 是否将表格和图片分开返回

## 业务逻辑

该方法的核心业务逻辑是从 PDF 页面中识别、分离并提取表格和图片及其标题，主要处理以下场景：

1. **分离表格和图片**：根据布局识别结果，将表格和图片从普通文本中分离出来
2. **合并跨页表格**：将跨多页的同一个表格合并为一个整体
3. **关联标题**：将表格/图片的标题与对应的表格/图片关联
4. **去除干扰文本**：过滤掉数据来源等非核心信息
5. **生成裁剪图像**：根据需要生成表格和图片的裁剪图像
6. **构建表格结构**：将表格文本块转换为结构化的表格数据

## 执行流程

### 阶段 1：提取表格和图片框（第872-904行）

1. **初始化数据结构**
   - tables: 字典，以 "页码-布局编号" 为键，存储表格文本块列表
   - figures: 字典，以 "页码-布局编号" 为键，存储图片文本块列表
   - nomerge_lout_no: 列表，记录不应合并的表格/图片布局编号

2. **遍历所有文本块**
   - 跳过没有 layoutno 的文本块
   - **标记不可合并对象**：如果文本块是标题类型（table caption/title/figure caption/reference），标记前一个布局不可合并
   - **提取表格**：
     - 检查是否为来源标注（如"数据来源："），如果是则删除
     - 将表格文本块添加到 tables 字典
     - 从 self.boxes 中移除
   - **提取图片**：
     - 仅当 need_image=True 时处理
     - 检查是否为来源标注，如果是则删除
     - 将图片文本块添加到 figures 字典
     - 从 self.boxes 中移除

### 阶段 2：合并跨页表格（第906-924行）

1. **将 nomerge_lout_no 转换为集合**，便于快速查找

2. **按位置排序表格**：根据 top 和 x0 坐标对所有表格进行排序

3. **遍历相邻表格判断是否合并**：
   - 如果前一个表格在 nomerge_lout_no 中，跳过（有标题，不能合并）
   - 如果两个表格在同一页，跳过
   - 如果两个表格页码差距大于1，跳过（不是连续页）
   - **判断垂直距离**：如果垂直距离大于平均行高的23倍，跳过（间距太大，不是同一个表）
   - **合并**：将后一个表格的文本块追加到前一个，删除后一个表格

### 阶段 3：关联标题（第926-963行）

1. **定义水平重叠判断函数**
   如果两个框在水平方向上有重叠，返回 True

2. **遍历剩余文本块查找标题**
   - 使用 TableStructureRecognizer.is_caption() 判断是否为标题
   - 标题识别模式：[图表]+[ 0-9:：]{2,} （如"表1："、"图2："）

3. **查找最近的表格或图片**
   - 定义嵌套函数 nearest(tbls) 查找最近的表格/图片
   - 遍历所有表格/图片的文本块，跳过已包含 caption 的
   - 计算欧氏距离：dis = y_dis² + x_dis²
   - 返回距离最近的键和距离值

4. **将标题关联到最近的表格或图片**
   - 比较到表格和图片的距离
   - 关联到距离更近的一个
   - 将标题插入到对应表格/图片列表的首位
   - 从 self.boxes 中移除标题

### 阶段 4：裁剪函数定义（第965-989行）

定义嵌套函数 cropout(bxs, ltype, poss) 用于裁剪表格或图片：

1. **获取涉及的页码集合**

2. **单页情况**（len(pn) < 2）：
   - 计算边界框（x0, top, x1, bottom）
   - 在该页布局中查找与类型匹配的布局框
   - 使用 Recognizer.find_overlapped() 找到最大重叠的布局
   - 调用 self.page_images[pn].crop() 进行裁剪
   - 记录位置信息到 poss 列表

3. **多页情况**（跨页）：
   - 按页码分组文本块
   - 递归调用 cropout 裁剪每一页
   - 创建新图像，按垂直顺序拼接所有页的裁剪图
   - 背景色设为浅灰色 (245, 245, 245)

### 阶段 5：处理图片并裁剪（第991-1004行）

1. 遍历 figures 字典中的所有图片
2. 合并所有文本块的内容（用换行符连接）
3. 调用 cropout() 裁剪图片
4. 根据 separate_tables_figures 参数决定返回方式

### 阶段 6：处理表格并构建结构（第1006-1013行）

1. 遍历 tables 字典中的所有表格
2. 跳过空表格
3. **按Y轴排序**：使用 Recognizer.sort_Y_firstly() 对表格文本块排序
4. **构建表格结构**：调用 self.tbl_det.construct_table() 将文本块转换为表格
5. 调用 cropout() 裁剪表格图像
6. 添加到结果列表

### 阶段 7：返回结果（第1015-1040行）

根据参数组合返回不同结果。

## 相关技术点

### 1. 布局识别（Layout Recognition）

- self.boxes: 存储所有文本块的列表，每个块包含布局信息
- layout_type: 文本块类型（table/figure/text/table caption等）
- layoutno: 布局编号，用于标识同一布局内的所有文本块
- 使用深度学习模型进行布局识别
- 支持 ONNX 和 Ascend 两种推理引擎

### 2. 标题识别（Caption Recognition）

- 识别规则：正则表达式 [图表]+[ 0-9:：]{2,}
- 布局类型检查：layout_type 包含 "caption"
- 实现位置：deepdoc/vision/table_structure_recognizer.py

### 3. 表格结构识别（Table Structure Recognition）

- 将表格文本块转换为结构化表格
- 支持 HTML 和文本两种输出格式
- 处理英文和中文表格
- 实现位置：self.tbl_det: TableStructureRecognizer 实例

### 4. 跨页表格合并

- 合并条件：连续两页、垂直距离 < 平均行高 × 23、前一个表格没有标题
- 基于平均行高动态判断
- 避免误合并有标题的表格

### 5. 图像裁剪（Image Cropping）

- 使用 PIL (Pillow) 进行图像处理
- 基于 pdfplumber 的高分辨率页面图像
- 通过 page_images[pn].crop() 裁剪指定区域
- 坐标需要乘以缩放倍数 ZM 进行转换

### 6. 位置信息计算

- 位置数据结构：(page_number, left, right, top, bottom)
- 存储于 positions 和 figure_positions 列表

### 7. 距离计算

- 水平距离：_x_dis(a, b) 方法
- 垂直距离：_y_dis(a, b) 方法
- 欧氏距离：用于标题到表格/图片的最近邻搜索

### 8. 重叠检测（Overlap Detection）

- Recognizer.find_overlapped(): 在排序的框列表中快速找到与目标框重叠最大的框
- 使用二分查找 + 精确计算的优化策略

### 9. 数据过滤

- 数据来源标注：(数据|资料|图表)*来源[:： ]
- 空文本：不提取文本为空的表格/图片
- 无布局编号：跳过没有 layoutno 的文本块

### 10. 坐标系统

- 页面坐标：x0, x1, top, bottom, page_number
- 累计高度：page_cum_height 用于跨页计算绝对垂直位置

## 输出结果

**返回格式：**

1. **默认模式**（separate_tables_figures=False）：
   - res: 列表，每个元素为 (image, table_content/figure_text)
   - positions: 列表，每个元素为位置元组 (page, left, right, top, bottom)

2. **分离模式**（separate_tables_figures=True）：
   - res: 表格结果列表
   - figure_results: 图片结果列表
   - positions: 表格位置列表
   - figure_positions: 图片位置列表

**表格内容格式：**
- return_html=True: HTML 表格字符串
- return_html=False: 文本表格（二维列表）

## 总结

_extract_table_figure 方法是 RAGFlow PDF 解析流程中的关键组件，它通过以下方式实现高质量的表格和图片提取：

1. **智能分离**：基于布局识别结果精确分离表格和图片
2. **跨页处理**：智能识别并合并跨页表格
3. **标题关联**：使用最近邻算法将标题关联到正确的表格/图片
4. **灵活输出**：支持多种返回格式，满足不同业务需求
5. **鲁棒性**：通过多重过滤和验证确保提取质量

该方法充分利用了深度学习布局识别、图像处理、几何计算等多种技术，为后续的表格解析和图片理解提供了高质量的数据基础。
