## 📋 概述

引用插入与自动标注是 RAGFlow 系统中的**核心答案增强功能**，负责在 LLM 生成的答案中自动插入引用标记，并将答案与检索到的知识块关联起来。该机制确保答案的可信度、可验证性和透明度。

```
┌─────────────────────────────────────────────────────────┐
```

## 🎯 核心业务价值

### 为什么需要引用标注？

1. **可信度提升**
   - 用户可以验证答案来源
   - 避免LLM幻觉（Hallucination）
   - 提供证据支持

2. **透明度增强**
   - 明确指出知识来源
   - 用户可以深入了解
   - 建立信任关系

3. **用户体验优化**
   - 一键查看原始文档
   - 快速定位相关内容
   - 提升专业感

4. **质量控制**
   - 避免错误信息
   - 支持事实核查
   - 便于审计和追溯

```python

    chunk_v,               # 所有chunk向量
    answer_tokens,         # 答案片段分词

# vtsim: 向量相似度数组 (array[float])
```

**混合相似度公式**：

```
sim[i] = tkweight * tksim[i] + vtweight * vtsim[i]
       = 0.1 * tksim[i] + 0.9 * vtsim[i]
```

**阈值计算**：


**为什么乘以0.99？**

1. **避免自匹配**
   - 防止答案片段与自身过度匹配
   - 引入微小的惩罚

2. **提升质量**
   - 只选择高度相关的chunks
   - 避免边界情况

## 方法2: repair_bad_citation_formats() - 修复引用格式

**文件位置**: [api/db/services/dialog_service.py:252-278](../../../../api/db/services/dialog_service.py#L252-L278)

### 核心业务逻辑

```python
# 定义不规范的引用格式
BAD_CITATION_PATTERNS = [
    re.compile(r"\(\s*ID\s*[: ]*\s*(\d+)\s*\)"),  # (ID: 12)
    re.compile(r"\[\s*ID\s*[: ]*\s*(\d+)\s*\]"),  # [ID: 12]
    re.compile(r"【\s*ID\s*[: ]*\s*(\d+)\s*】"),  # 【ID: 12】
    re.compile(r"ref\s*(\d+)", flags=re.IGNORECASE),  # ref12、REF 12
]

def repair_bad_citation_formats(answer: str, kbinfos: dict, idx: set):
    max_index = len(kbinfos["chunks"])

    def safe_add(i):
        if 0 <= i < max_index:
            idx.add(i)
            return True
        return False

    def find_and_replace(pattern, group_index=1, repl=lambda i: f"ID:{i}", flags=0):
        nonlocal answer

        def replacement(match):
            try:
                i = int(match.group(group_index))
                if safe_add(i):
                    return f"[{repl(i)}]"
            except Exception:
                pass
            return match.group(0)

        answer = re.sub(pattern, replacement, answer, flags=flags)

    for pattern in BAD_CITATION_PATTERNS:
        find_and_replace(pattern)

    return answer, idx
```

### 不规范引用格式列表

| 模式 | 示例 | 标准格式 |
|------|------|---------|
| `(ID: 12)` | `(ID: 0)` | `[ID:0]` |
| `[ID: 12]` | `[ID: 0]` | `[ID:0]` |
| `【ID: 12】` | `【ID: 0】` | `[ID:0]` |
| `ref12` | `ref0` | `[ID:0]` |
| `REF 12` | `REF 0` | `[ID:0]` |

        for c in refs["chunks"]:

                del c["vector"]

    # 5. 处理API错误提示

## 📋 引用提示词模板

**文件位置**: [rag/prompts/citation_prompt.md](../../../../rag/prompts/citation_prompt.md)

### 核心规则

```markdown
## Citation Requirements:

## Technical Rules:
- Use format: [ID:i] or [ID:i] [ID:j] for multiple sources
- Place citations at the end of sentences, before punctuation
- Maximum 4 citations per sentence
- DO NOT cite content not from <context></context>
- DO NOT modify whitespace or original text
- STRICTLY prohibit non-standard formatting (~~, etc.)

## What MUST Be Cited:
1. **Quantitative data**: Numbers, percentages, statistics, measurements
2. **Temporal claims**: Dates, timeframes, sequences of events
3. **Causal relationships**: Claims about cause and effect
4. **Comparative statements**: Rankings, comparisons, superlatives
5. **Technical definitions**: Specialized terms, concepts, methodologies
6. **Direct attributions**: What someone said, did, or believes
7. **Predictions/forecasts**: Future projections, trend analyses
8. **Controversial claims**: Disputed facts, minority opinions

## What Should NOT Be Cited:
- Common knowledge (e.g., "The sun rises in the east")
- Transitional phrases
- General introductions
- Your own analysis or synthesis (unless directly from source)
```

## 🎯 关键设计决策

### 1. 为什么使用动态阈值？

**原因**：
1. 平衡精确度和召回率
2. 自适应不同场景
3. 避免过度引用

**示例**：
```python
thr = 0.63
while thr > 0.3 and len(cites.keys()) == 0:
    thr *= 0.8
```

### 2. 为什么最多4个引用？

**原因**：
1. 可读性：引用过多影响阅读
2. 相关性：保留最相关的chunks
3. 性能：减少渲染负担

### 3. 为什么要去重引用？

**原因**：
1. 避免冗余
2. 简化展示
3. 提升体验

**示例**：
```python
# 不去重（冗余）
"深度学习很重要 [ID:0]。神经网络是基础 [ID:0][ID:1]。"

# 去重后（简洁）
"深度学习很重要 [ID:0]。神经网络是基础 [ID:0][ID:1]。反向传播是关键。"
```

### 4. 为什么要保护代码块？

**原因**：
1. 代码完整性
2. 避免误匹配
3. 代码不需要引用
