## 二、业务逻辑

### A. 核心目标

**垂直方向合并同一列内的相邻文本框，构建完整段落**

在 `_text_merge` 完成水平合并后，文档中的文本可能仍然是片段化的：
- 一个段落可能被分为多个文本框
- OCR识别可能导致行间断裂
- 需要根据上下文语义和空间关系进行垂直合并

`_naive_vertical_merge` 的作用是：
1. 在同一列内垂直合并文本框
2. 基于多种特征判断是否应该合并
3. 构建语义连贯的段落

### B. 与其他合并方法的区别

| 方法 | 合并方向 | 合并维度 | 使用场景 | 算法复杂度 |
|------|---------|---------|----------|-----------|
| **_text_merge** | 水平 | 同一行内相邻框 | 将单词合并为句子 | O(n) |
| **_naive_vertical_merge** | **垂直** | **上下相邻框** | **将句子合并为段落** | **O(n)** |
| **_concat_downward** | 垂直 | 跨行跨页 | 使用XGBoost智能合并 | O(n²) |
| **_final_reading_order_merge** | 重排 | 调整阅读顺序 | 确保正确的阅读顺序 | O(n²) |

### C. 输入依赖

| 依赖项 | 来源 | 用途 |
|--------|------|------|
| `self.boxes` | `_text_merge()` 和 `_concat_downward()` | 已进行水平合并的文本框列表 |
| `self.mean_height` | `__images__()` | 平均字符高度，用于判断Y轴距离 |
| `self.mean_width` | `__images__()` | 平均字符宽度，用于判断X轴距离 |
| `self.is_english` | 配置 | 是否为英文文档，影响标点符号判断 |

### D. 输出结果

增强的 `self.boxes`，其中：
- 每个文本框的 `col_id` 字段已分配
- 同一列内垂直相邻的文本框被合并
- 文本更完整、连贯，形成段落

### 步骤1: 列识别与分配（[pdf_parser.py:598](pdf_parser.py#L598)）


**作用**：为所有文本框分配列ID（col_id）

**`_assign_column` 方法详解**：

参见 [assign_column.md](../305-text_merge-文本语义合并/assign_column.md)，核心步骤包括：
1. 按页分组
2. 缩进容错处理（12%页面宽度）

### 步骤2: 按页和列分组（[pdf_parser.py:600-602](pdf_parser.py#L600-L602)）

```python
grouped = defaultdict(list)
for b in bxs:
    grouped[(b["page_number"], b.get("col_id", 0))].append(b)
```

**数据结构示例**：

```python
# 输入
bxs = [
    {"text": "第1页第1列文本1", "page_number": 1, "col_id": 0, "top": 100},
    {"text": "第1页第2列文本1", "page_number": 1, "col_id": 1, "top": 100},
    {"text": "第1页第1列文本2", "page_number": 1, "col_id": 0, "top": 150},
    {"text": "第2页第1列文本1", "page_number": 2, "col_id": 0, "top": 100},
]

# 分组结果
grouped = {
    (1, 0): [
        {"text": "第1页第1列文本1", "page_number": 1, "col_id": 0, "top": 100},
        {"text": "第1页第1列文本2", "page_number": 1, "col_id": 0, "top": 150},
    ],
    (1, 1): [
        {"text": "第1页第2列文本1", "page_number": 1, "col_id": 1, "top": 100},
    ],
    (2, 0): [
        {"text": "第2页第1列文本1", "page_number": 2, "col_id": 0, "top": 100},
    ],
}
```

**为什么按 (page_number, col_id) 分组？**
- 不同页的文本框通常不应合并（除非满足特殊条件）
- 不同列的文本框属于不同的阅读流，不能合并

### 步骤3: 排序与初始化（[pdf_parser.py:604-610](pdf_parser.py#L604-L610)）

```python
merged_boxes = []
for (pg, col), bxs in grouped.items():
    bxs = sorted(bxs, key=lambda x: (x["top"], x["x0"]))  # 按Y轴和X轴排序
    if not bxs:
        continue

    # 计算平均高度
    mh = self.mean_height[pg - 1] if self.mean_height else np.median([b["bottom"] - b["top"] for b in bxs]) or 10
```

**排序规则**：
1. **优先按top排序**：确保从上到下处理
2. **次要按x0排序**：同Y位置的框按左到右排序

**平均高度计算**：
- 优先使用 `self.mean_height[pg - 1]`（全局平均高度）
- 如果不存在，使用当前页的中位数高度
- 如果仍不存在，默认为10

### 步骤4: 预处理过滤（[pdf_parser.py:612-627](pdf_parser.py#L612-L627)）

#### 4.1 移除跨页的孤立标题

```python
i = 0
while i + 1 < len(bxs):
    b = bxs[i]
    b_ = bxs[i + 1]

    if b["page_number"] < b_["page_number"] and re.match(r"[0-9  •一—-]+$", b["text"]):
        bxs.pop(i)
        continue
```

**作用**：移除跨页时产生的孤立标题

**示例**：

```python
# 场景：第1页末尾
b = {"text": "1", "page_number": 1}  # 章节编号
b_ = {"text": "第2页正文", "page_number": 2}

# 正则匹配：r"[0-9  •一—-]+$"
# "1" 匹配 → 移除
```

**为什么需要这个过滤？**
- 跨页时，章节编号可能被孤立识别
- 这些编号会在下一页重新出现
- 移除它们可以避免重复

---

#### 4.2 移除空文本框

```python
if not b["text"].strip():
    bxs.pop(i)
    continue
```

**作用**：移除空文本框或仅包含空白字符的框

---

#### 4.3 检查layout一致性

```python
if not b["text"].strip() or b.get("layoutno") != b_.get("layoutno"):
    i += 1
    continue
```

**条件**：
- 当前框为空（已在前面处理）
- 两个框不在同一个layout区域

**为什么layout不一致就不合并？**
- 不同layout区域可能属于不同的内容块
- 例如：标题layout和正文layout不应合并

---

### 步骤5: 基础条件检查（[pdf_parser.py:629-636](pdf_parser.py#L629-L636)）

#### 5.1 Y轴距离检查

```python
if b_["top"] - b["bottom"] > mh * 1.5:
    i += 1
    continue
```

**阈值**：1.5倍的平均字符高度

**示例**：

```python
# 场景1: 正常行间距
b["bottom"] = 120
b_["top"] = 130
mh = 12
distance = 130 - 120 = 10
threshold = 12 * 1.5 = 18
10 < 18  # ✅ 可以合并

# 场景2: 过大的间距（可能是不同段落）
b["bottom"] = 120
b_["top"] = 150
distance = 150 - 120 = 30
30 > 18  # ❌ 不合并
```

**为什么是1.5？**
- 太小（如1.0）：可能无法合并正常的行间距
- 太大（如3.0）：可能错误地合并不同段落
- 1.5是经验值，平衡了召回率和准确率

---

#### 5.2 水平重叠检查

```python
overlap = max(0, min(b["x1"], b_["x1"]) - max(b["x0"], b_["x0"]))
if overlap / max(1, min(b["x1"] - b["x0"], b_["x1"] - b_["x0"])) < 0.3:
    i += 1
    continue
```

**重叠度计算**：

```
框b:     ┌──────────────┐
         x0=100   x1=200
框b_:        ┌──────────────┐
             x0=150   x1=250

重叠部分:     ┌────────┐
              150    200

overlap = min(200, 250) - max(100, 150)
        = 200 - 150
        = 50

min_width = min(200-100, 250-150)
          = min(100, 100)
          = 100

overlap_ratio = 50 / 100 = 0.5 = 50%

50% >= 30%  # ✅ 可以合并
```

**为什么需要水平重叠？**
- 确保文本在同一列的同一垂直对齐线上
- 防止合并不同缩进级别的文本（如列表项）

### 步骤6: 标点符号特征判断（[pdf_parser.py:638-663](pdf_parser.py#L638-L663)）

这是**核心算法**，使用三种特征进行合并决策。

#### 6.1 促合并特征（concatting_feats）

```python
concatting_feats = [
    b["text"].strip()[-1] in ",;:'\"，、'"'；：-",  # 特征1: 上一个框以逗号等结尾
    len(b["text"].strip()) > 1 and b["text"].strip()[-2] in ",;:'\"，'"'、；：",  # 特征2: 倒数第2个字符是标点
    b_["text"].strip() and b_["text"].strip()[0] in "。；？?!"")）),，、：",  # 特征3: 下一个框以右引号等开头
]
```

**特征详解**：

| 特征 | 示例 | 说明 |
|------|------|------|
| **特征1** | "Hello," | 逗号表示句子未结束 |
| **特征2** | "Hello," | 处理空格情况（"Hello, "） |
| **特征3** | "world") | 右括号表示连续性 |

**示例**：

```python
# 示例1: 逗号促合并
b["text"] = "Hello,"
b_["text"] = " world"
concatting_feats = [True, False, False]
# 任何为True → 促合并

# 示例2: 右引号促合并
b["text"] = "Hello"
b_["text"] = ") world"
concatting_feats = [False, False, True]
# 任何为True → 促合并
```

---

#### 6.2 阻合并特征（feats）

```python
feats = [
    b.get("layoutno", 0) != b_.get("layoutno", 0),  # 特征1: 不同layout
    b["text"].strip()[-1] in "。？?!",               # 特征2: 上一个框以句号等结尾
    self.is_english and b["text"].strip()[-1] in ".!?",  # 特征3: 英文句号等
    b["page_number"] == b_["page_number"] and b_["top"] - b["bottom"] > self.mean_height[b["page_number"] - 1] * 1.5,  # 特征4: Y轴距离过大
    b["page_number"] < b_["page_number"] and abs(b["x0"] - b_["x0"]) > self.mean_width[b["page_number"] - 1] * 4,  # 特征5: 跨页时X轴偏移过大
]
```

**特征详解**：

| 特征 | 示例 | 说明 |
|------|------|------|
| **特征1** | layoutno="0" vs layoutno="1" | 不同内容块 |
| **特征2** | "结束。" | 句号表示句子结束 |
| **特征3** | "End." (英文) | 英文句号 |
| **特征4** | Y距离 > 1.5 * mean_height | 同页间距过大 |
| **特征5** | X偏移 > 4 * mean_width | 跨页时对齐偏差大 |

**示例**：

```python
# 示例1: 句号阻合并
b["text"] = "Hello world."
b_["text"] = "New sentence"
feats = [False, True, False, False, False]
# 任何为True → 阻合并（除非有促合并特征）

# 示例2: 跨页但X偏移大
b["text"] = "第1页末尾", "x0": 100, "page_number": 1
b_["text"] = "第2页开头", "x0": 300, "page_number": 2
mean_width = 12
abs(100 - 300) = 200 > 12 * 4 = 48  # 阻合并
```

---

#### 6.3 空间分离特征（detach_feats）

```python
detach_feats = [b["x1"] < b_["x0"], b["x0"] > b_["x1"]]
```

**特征详解**：

```
情况1: b在b_左侧
框b:  ┌────┐
      x1=150
框b_:       ┌────┐
            x0=200

b["x1"] < b_["x0"]  # 150 < 200 → True → 分离

情况2: b在b_右侧
框b_: ┌────┐
       x1=150
框b:        ┌────┐
            x0=200

b["x0"] > b_["x1"]  # 200 > 150 → True → 分离
```

**为什么需要这个检查？**
- 即使Y轴距离很近，如果X轴完全分离，也不应合并
- 例如：双栏文档，两栏的文本不应合并

---

#### 6.4 合并决策逻辑

```python
if (any(feats) and not any(concatting_feats)) or any(detach_feats):
    logging.debug(
        "{} {} {} {}".format(
            b["text"],
            b_["text"],
            any(feats),
            any(concatting_feats),
        )
    )
    i += 1
    continue
```

**决策规则**：

| 条件 | 结果 | 说明 |
|------|------|------|
| `any(feats)` 且 `not any(concatting_feats)` | **不合并** | 有阻合并特征且无促合并特征 |
| `any(detach_feats)` | **不合并** | 空间上完全分离 |
| 其他情况 | **合并** | 无阻合并特征或有促合并特征 |

**决策表**：

| any(feats) | any(concatting_feats) | any(detach_feats) | 结果 |
|------------|----------------------|-------------------|------|
| True | False | - | 不合并 |
| True | True | - | 合并（促合并优先） |
| False | - | True | 不合并 |
| False | - | False | 合并 |

**示例**：

```python
# 示例1: 逗号促合并（优先级高）
b["text"] = "Hello,"
b_["text"] = " world"
feats = [False, False, False, False, False]  # any(feats)=False
concatting_feats = [True, False, False]      # any(concatting_feats)=True
detach_feats = [False, False]                # any(detach_feats)=False
# → 合并

# 示例2: 句号阻合并（优先级高）
b["text"] = "End."
b_["text"] = "New start"
feats = [False, True, False, False, False]   # any(feats)=True
concatting_feats = [False, False, False]     # any(concatting_feats)=False
detach_feats = [False, False]                # any(detach_feats)=False
# → 不合并

# 示例3: 空间分离
b["text"] = "第1列", "x0": 100, "x1": 200
b_["text"] = "第2列", "x0": 250, "x1": 350
feats = [False, False, False, False, False]  # any(feats)=False
concatting_feats = [False, False, False]     # any(concatting_feats)=False
detach_feats = [True, False]                 # any(detach_feats)=True
# → 不合并
```

### 步骤7: 执行合并操作（[pdf_parser.py:665-669](pdf_parser.py#L665-L669)）

```python
b["text"] = (b["text"].rstrip() + " " + b_["text"].lstrip()).strip()
b["bottom"] = b_["bottom"]
b["x0"] = min(b["x0"], b_["x0"])
b["x1"] = max(b["x1"], b_["x1"])
bxs.pop(i + 1)
```

**合并操作详解**：

| 字段 | 操作 | 说明 |
|------|------|------|
| **text** | `(text1.rstrip() + " " + text2.lstrip()).strip()` | 去除尾随空格 + 空格 + 去除前导空格 + 整体去除首尾空格 |
| **bottom** | `b_["bottom"]` | 扩展下边界到第二个框的下边界 |
| **x0** | `min(x0)` | 可能扩展左边界（如果第二个框更左） |
| **x1** | `max(x1)` | 可能扩展右边界（如果第二个框更右） |
| **列表操作** | `bxs.pop(i + 1)` | 删除第二个框（已被合并） |

**示例**：

```python
# 合并前
b = {
    "text": "Hello,  ",
    "x0": 100,
    "x1": 200,
    "top": 100,
    "bottom": 120,
}
b_ = {
    "text": "  world",
    "x0": 100,
    "x1": 220,
    "top": 130,
    "bottom": 150,
}

# 合并后
b = {
    "text": "Hello, world",  # rstrip() + " " + lstrip() + strip()
    "x0": 100,               # min(100, 100)
    "x1": 220,               # max(200, 220)
    "top": 100,              # 保持不变
    "bottom": 150,           # 扩展到150
}

# 列表变化
bxs = [b, b_, ...]  # 合并前
bxs = [b, ...]      # 合并后（b_被删除）
```

**可视化**：

```
合并前:
┌────────────┐
│ Hello,     │  bottom=120
└────────────┘
              ↓ 10pt gap
┌──────────────┐
│ world        │  bottom=150
└──────────────┘

合并后:
┌──────────────┐
│ Hello, world │  bottom=150
└──────────────┘
```

### 步骤8: 排序输出（[pdf_parser.py:671-673](pdf_parser.py#L671-L673)）

```python
merged_boxes.extend(bxs)

self.boxes = sorted(merged_boxes, key=lambda x: (x["page_number"], x.get("col_id", 0), x["top"]))
```

**排序规则**：
1. **优先按page_number排序**：确保从第1页到最后1页
2. **次要按col_id排序**：确保从左列到右列
3. **最后按top排序**：确保从上到下

**示例**：

```python
# 合并后的所有文本框
merged_boxes = [
    {"text": "第2页第2列", "page_number": 2, "col_id": 1, "top": 100},
    {"text": "第1页第1列", "page_number": 1, "col_id": 0, "top": 100},
    {"text": "第1页第2列", "page_number": 1, "col_id": 1, "top": 100},
```

## 四、技术要点

### A. 标点符号特征工程

**设计思路**：

1. **促合并特征**（concatting_feats）：
   - 逗号、分号：句子未结束
   - 右引号、右括号：引用或函数调用未结束
   - 冒号、破折号：列表或说明开始

2. **阻合并特征**（feats）：
   - 句号、问号、感叹号：句子结束
   - 英文句号：英文句子结束
   - Layout不一致：不同内容块
   - Y轴距离过大：不同段落
   - 跨页X偏移过大：可能不是同一列

3. **空间分离特征**（detach_feats）：
   - 完全无水平重叠：不同列
   - 防止跨列合并

**为什么使用特征组合？**

```python
# 场景1: 逗号优先级高
b["text"] = "Hello,"  # 促合并
b_["text"] = " world"  # 阻合并（Y距离大）
# 促合并特征 → 合并

# 场景2: 句号优先级高
b["text"] = "End."  # 阻合并
b_["text"] = "Next"  # 促合并（右引号）
# 阻合并特征 → 不合并
```

**优先级规则**：
```
空间分离 > 促合并特征 > 阻合并特征
```

---

### B. 水平重叠计算

```python
overlap = max(0, min(b["x1"], b_["x1"]) - max(b["x0"], b_["x0"]))
overlap_ratio = overlap / max(1, min(b["x1"] - b["x0"], b_["x1"] - b_["x0"]))
```

**几何意义**：

```
情况1: 完全重叠
框b:  ┌──────────┐
框b_: ┌──────────┐
overlap = b["x1"] - b["x0"] = full_width
overlap_ratio = 1.0 = 100%

情况2: 部分重叠
框b:  ┌──────────┐
框b_:    ┌──────────┐
overlap = b_["x0"] < x < b["x1"]
overlap_ratio = 0.5 = 50%

情况3: 无重叠
框b:  ┌────┐
框b_:         ┌────┐
overlap = 0
overlap_ratio = 0%
```

**为什么阈值是30%？**

- **太低（如10%）**：可能合并不同缩进级别的文本
- **太高（如70%）**：可能错过应该合并的文本（OCR检测误差）
- **30%是经验值**：平衡了召回率和准确率

---

### C. 跨页合并处理

```python
# 特征5: 跨页时X轴偏移过大
b["page_number"] < b_["page_number"] and abs(b["x0"] - b_["x0"]) > self.mean_width[b["page_number"] - 1] * 4
```

**示例**：

```python
# 场景1: 正常跨页（同一列）
b["page_number"] = 1, "x0" = 100
b_["page_number"] = 2, "x0" = 105
mean_width = 12
abs(100 - 105) = 5 < 12 * 4 = 48
# → 可以合并

# 场景2: 异常跨页（不同列）
b["page_number"] = 1, "x0" = 100
b_["page_number"] = 2, "x0" = 300
abs(100 - 300) = 200 > 48
# → 不合并
```

**为什么需要这个检查？**
- 跨页时，列对齐可能因为页面边距变化而偏移
- 但偏移过大说明不是同一列
- 4倍平均字符宽度是合理的容差

---

### D. 孤立标题过滤

```python
if b["page_number"] < b_["page_number"] and re.match(r"[0-9  •一—-]+$", b["text"]):
    bxs.pop(i)
```

**正则表达式详解**：

```
[0-9  •一—-]+$

匹配:
- "1" ✓
- "第一章" ✓
- "——" ✓
- "1  " ✓

不匹配:
- "第一章 引言" ✗ (有其他字符)
- "Chapter 1" ✗ (有英文字母)
```

**为什么需要这个过滤？**

```
场景: 跨页的章节标题

第1页末尾:
┌────────┐
│ 一、    │  ← 孤立的章节编号
└────────┘

第2页开头:
┌────────┐
│ 一、    │  ← 完整的章节标题
│ 引言    │
└────────┘

如果不过滤:
会保留第1页的孤立编号，导致重复
```

---

### E. 边界情况处理

| 情况 | 处理方式 | 代码 |
|------|---------|------|
| **空列表** | `if not bxs: continue` | 跳过空组 |
| **空文本框** | `if not b["text"].strip(): bxs.pop(i)` | 删除空框 |
| **平均高度不存在** | 使用中位数或默认值10 | `np.median(...) or 10` |
| **除零保护** | `max(1, min_width)` | 防止除以0 |
| **col_id不存在** | 使用默认值0 | `b.get("col_id", 0)` |
| **layoutno不存在** | 使用默认值0 | `b.get("layoutno", 0)` |

## 八、常见问题与调试

### A. 文本框未合并

**可能原因**：
1. Y轴距离过大（> 1.5 * mean_height）
2. 水平重叠不足（< 30%）
3. 有阻合并特征（句号、问号等）
4. layout不一致
5. 空间分离（无水平重叠）

**调试方法**：

```python
# 检查1: 查看Y轴距离
for i in range(len(bxs) - 1):
    b, b_ = bxs[i], bxs[i + 1]
    y_dis = b_["top"] - b["bottom"]
    threshold = mh * 1.5
    print(f"Y距离: {y_dis}, 阈值: {threshold}, 是否合并: {y_dis < threshold}")

# 检查2: 查看水平重叠
overlap = max(0, min(b["x1"], b_["x1"]) - max(b["x0"], b_["x0"]))
min_width = min(b["x1"] - b["x0"], b_["x1"] - b_["x0"])
overlap_ratio = overlap / max(1, min_width)
print(f"水平重叠: {overlap_ratio:.2%}, 阈值: 30%")

# 检查3: 查看标点特征
concatting_feats = [
    b["text"].strip()[-1] in ",;:'\"，、'"'；：-",
    # ...
]
feats = [
    b["text"].strip()[-1] in "。？！?",
    # ...
]
print(f"促合并特征: {any(concatting_feats)}, 阻合并特征: {any(feats)}")

# 检查4: 查看layout信息
print(f"layoutno: {b.get('layoutno')} vs {b_.get('layoutno')}")
```

---

### B. 错误合并

**可能原因**：
1. 阈值太大
2. 标点符号识别错误
3. layout分配错误
4. 列识别错误

**调试方法**：

```python
# 降低阈值，减少误合并
if b_["top"] - b["bottom"] > mh * 1.0:  # 从1.5改为1.0
    i += 1
    continue

# 提高水平重叠阈值
if overlap_ratio < 0.5:  # 从0.3改为0.5
    i += 1
    continue

# 添加更多阻合并特征
feats = [
    # ...
    b["text"].strip()[-1] in ":",  # 添加冒号
]
```

### C. 性能问题

**优化方向**：

1. **减少分组数量**：
   ```python
   # 只处理有多个框的组
   for (pg, col), bxs in grouped.items():
       if len(bxs) < 2:
           merged_boxes.extend(bxs)
           continue
   ```

2. **提前终止**：
   ```python

       i += 1
       continue
   ```

3. **缓存标点符号判断结果**：
   ```python

   cache = {}
   def get_feats(text):
       if text not in cache:
   ```

## 九、总结

### 核心功能

`_naive_vertical_merge` 是PDF解析流程中**垂直文本合并**的关键步骤：

1. ✅ **列识别**: 使用KMeans聚类识别文档列数
2. ✅ **按页列分组**: 确保合并只发生在同页同列
3. ✅ **多条件判断**: 基于layout、Y距离、水平重叠、标点符号等特征
4. ✅ **智能决策**: 促合并特征 vs 阻合并特征的优先级规则
5. ✅ **跨页支持**: 处理跨页段落的合并
6. ✅ **排序输出**: 确保正确的阅读顺序

### 技术亮点

| 特性 | 说明 |
|------|------|
| **特征工程** | 促合并特征、阻合并特征、空间分离特征三重判断 |
| **优先级规则** | 空间分离 > 促合并特征 > 阻合并特征 |
| **鲁棒性** | 完善的边界情况处理（空文本、除零保护等） |
| **可解释性** | 基于规则的决策，易于调试和优化 |
| **跨页支持** | 智能处理跨页段落合并 |
