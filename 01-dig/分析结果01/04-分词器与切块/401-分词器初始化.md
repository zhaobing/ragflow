4. **分割符配置**: 配置中英文混合文本的正则表达式分割规则

#### 步骤1: 初始化基础配置

**DENOMINATOR 的作用**:
- 用于词典词频的归一化计算
- 存储时: `F = int(log(freq/1000000) + 0.5)`
- 读取时: `freq = int(exp(F) * 1000000 + 0.5)`
- 通过对数变换压缩词频范围，减少存储空间

## 四、技术要点

### 4.1 Double-Array Trie (双数组Trie)

**选择 datrie 的原因**:

| 特性 | datrie | 普通Trie | Dict |
|------|--------|----------|------|
| 空间复杂度 | O(n) | O(n*字符集大小) | O(n) |
| 查询时间 | O(m) | O(m) | O(1) |
| 前缀搜索 | 支持 | 支持 | 不支持 |
| 内存占用 | 极低 | 高 | 中 |

**Trie树结构示例**:
```
根节点
 ├─ '人' → '工' → '智' → '能' (词频: 5000000, 词性: n)
 ├─ '机' → '器' → '学' → '习' (词频: 3000000, 词性: n)
 └─ '深' → '度' → '学' → '习' (词频: 2500000, 词性: n)
```

**双索引机制** ([line 47-51](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L47-L51)):
```python
def key_(self, line):
    return str(line.lower().encode("utf-8"))[2:-1]  # 正向索引

def rkey_(self, line):
    return str(("DD" + (line[::-1].lower())).encode("utf-8"))[2:-1]  # 反向索引
```

**为什么要双向索引？**
- **正向索引**: 正常匹配 "人工智能"
- **反向索引**: 支持逆向最大匹配算法，提升分词准确性

### 4.2 词频归一化算法

**存储格式** ([line 64](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L64)):
```python
F = int(log(freq / DENOMINATOR) + 0.5)
```

**示例计算**:
```
原始词频: 10000000
存储值:   int(log(10000000/1000000) + 0.5) = int(2.3 + 0.5) = 2

恢复:    int(exp(2) * 1000000 + 0.5) = 7389056 ≈ 10000000
```

**优势**:
- 压缩词频范围: 1-10000000 → 0-10
- 减少存储空间: int32 → int8
- 保留相对大小关系

```python
    # 1. 按 SPLIT_CHAR 分割
```

### 4.4 词典加载机制 (_load_dict)

**加载流程** ([line 53-74](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L53-L74)):

```python
def _load_dict(self, fnm):
    of = open(fnm, "r", encoding="utf-8")
    while True:
        line = of.readline()
        if not line:
            break

        # 解析行: 词语 频率 词性
        parts = re.split(r"[ \t]", line)
        word = parts[0]
        freq = parts[1]
        pos = parts[2]

        # 计算存储值
        k = self.key_(word)
        F = int(log(freq / self.DENOMINATOR) + 0.5)

        # 存储到Trie (保留高频词)
        if k not in self.trie_ or self.trie_[k][0] < F:
            self.trie_[k] = (F, pos)

        # 添加反向索引
        self.trie_[self.rkey_(word)] = 1

    # 保存缓存
    self.trie_.save(fnm + ".trie")
```

**词典文件示例** (huqie.txt):
```
人工智能	5000000	n
机器学习	3000000	n
深度学习	2500000	n
神经网络	2000000	n
自然语言处理	1500000	n
```

## 五、封装层实现 (rag/nlp/rag_tokenizer.py)

### 5.1 RagTokenizer 子类

**目的**: 根据 DOC_ENGINE 配置调整分词行为

```python
class RagTokenizer(infinity.rag_tokenizer.RagTokenizer):

    def tokenize(self, line: str) -> str:
        if settings.DOC_ENGINE_INFINITY:
            # Infinity引擎: 直接返回原文，由引擎内部处理
            return line
        else:
            # Elasticsearch: 使用RAGFlow的分词器
            return super().tokenize(line)

    def fine_grained_tokenize(self, tks: str) -> str:
        if settings.DOC_ENGINE_INFINITY:
            return tks
        else:
            return super().fine_grained_tokenize(tks)
```

| 函数 | 粒度 | 用途 |
|------|------|------|
| tokenize | 粗粒度 | 语义检索，保留完整词组 |

**示例**:
