# 706-重排序机制分析

## 1. 概述

RAGFlow中的重排序(Rerank)机制是检索增强生成(RAG)系统中的关键环节，用于在初始检索结果的基础上进行精细排序，提高最终返回给用户的相关性质量。

### 重排序的作用

1. **优化相关性**: 基于语义相关性对初始检索结果进行重新排序
2. **融合多种评分**: 结合向量相似度、关键词相似度和rank feature
3. **提升用户满意度**: 确保最相关的内容排在前面

## 4. 重排序实现机制

### 4.1 两种重排序模式

#### 模式1: 使用Rerank模型 (`rerank_by_model`)

当 `rerank_mdl` 不为空时使用，在 [rag/nlp/search.py:331-352](../../../rag/nlp/search.py#L331-L352)：

```python
def rerank_by_model(self, rerank_mdl, sres, query, tkweight=0.3,
                    vtweight=0.7, cfield="content_ltks",
                    rank_feature: dict | None = None):
    _, keywords = self.qryr.question(query)

    # 构建输入文本
    ins_tw = []
    for i in sres.ids:
        content_ltks = sres.field[i][cfield].split()
        title_tks = [t for t in sres.field[i].get("title_tks", "").split() if t]
        important_kwd = sres.field[i].get("important_kwd", [])
        tks = content_ltks + title_tks + important_kwd
        ins_tw.append(tks)

    # 关键词相似度
    tksim = self.qryr.token_similarity(keywords, ins_tw)

    # 向量重排序相似度
    vtsim, _ = rerank_mdl.similarity(query, [remove_redundant_spaces(" ".join(tks)) for tks in ins_tw])

    # Rank feature分数
    rank_fea = self._rank_feature_scores(rank_feature, sres)

    # 融合评分
    return tkweight * np.array(tksim) + vtweight * vtsim + rank_fea, tksim, vtsim
```

**评分公式**:
```
final_score = tkweight * token_similarity + vtweight * vector_similarity + rank_feature_score
```

#### 模式2: 本地重排序 (`rerank`)

当不使用Rerank模型时使用，在 [rag/nlp/search.py:292-329](../../../rag/nlp/search.py#L292-L329)：

```python
def rerank(self, sres, query, tkweight=0.3,
           vtweight=0.7, cfield="content_ltks",
           rank_feature: dict | None = None
           ):
    _, keywords = self.qryr.question(query)
    vector_size = len(sres.query_vector)
    vector_column = f"q_{vector_size}_vec"

    # 获取向量
    ins_embd = []
    for chunk_id in sres.ids:
        vector = sres.field[chunk_id].get(vector_column, zero_vector)
        if isinstance(vector, str):
            vector = [get_float(v) for v in vector.split("\t")]
        ins_embd.append(vector)

    # 构建文本权重
    ins_tw = []
    for i in sres.ids:
        content_ltks = list(OrderedDict.fromkeys(sres.field[i][cfield].split()))
        title_tks = [t for t in sres.field[i].get("title_tks", "").split() if t]
        question_tks = [t for t in sres.field[i].get("question_tks", "").split() if t]
        important_kwd = sres.field[i].get("important_kwd", [])
        # 权重分配: 内容*1 + 标题*2 + 重要关键词*5 + 问题*6
        tks = content_ltks + title_tks * 2 + important_kwd * 5 + question_tks * 6
        ins_tw.append(tks)

    # Rank feature分数
    rank_fea = self._rank_feature_scores(rank_feature, sres)

    # 混合相似度计算
    sim, tksim, vtsim = self.qryr.hybrid_similarity(
        sres.query_vector, ins_embd, keywords, ins_tw, tkweight, vtweight
    )

    return sim + rank_fea, tksim, vtsim
```

### 4.2 相似度计算机制

在 [rag/nlp/query.py:220-228](../../../rag/nlp/query.py#L220-L228) 中的 `hybrid_similarity()`：

```python
def hybrid_similarity(self, avec, bvecs, atks, btkss, tkweight=0.3, vtweight=0.7):
    from sklearn.metrics.pairwise import cosine_similarity
    import numpy as np

    # 向量相似度（余弦相似度）
    sims = cosine_similarity([avec], bvecs)

    # 文本相似度
    tksim = self.token_similarity(atks, btkss)

    if np.sum(sims[0]) == 0:
        return np.array(tksim), tksim, sims[0]

    # 融合评分
    return np.array(sims[0]) * vtweight + np.array(tksim) * tkweight, tksim, sims[0]
```

### 4.3 文本相似度计算

在 [rag/nlp/query.py:230-256](../../../rag/nlp/query.py#L230-L256) 中的 `token_similarity()` 和 `similarity()`：

```python
def token_similarity(self, atks, btkss):
    def to_dict(tks):
        if isinstance(tks, str):
            tks = tks.split()
        d = defaultdict(int)
        wts = self.tw.weights(tks, preprocess=False)
        for i, (t, c) in enumerate(wts):
            d[t] += c
        return d

    atks = to_dict(atks)
    btkss = [to_dict(tks) for tks in btkss]
    return [self.similarity(atks, btks) for btks in btkss]

def similarity(self, qtwt, dtwt):
    # 基于词频权重计算相似度
    s = 1e-9
    for k, v in qtwt.items():
        if k in dtwt:
            s += v
    q = 1e-9
    for k, v in qtwt.items():
        q += v
    return s/q
```

## 5. Rank Feature机制

### 5.1 Rank Feature的作用

Rank Feature是基于标签特征(Tags)和PageRank的额外评分机制，在 [rag/nlp/search.py:265-290](../../../rag/nlp/search.py#L265-L290)：

```python
def _rank_feature_scores(self, query_rfea, search_res):
    rank_fea = []
    pageranks = []

    # 获取PageRank分数
    for chunk_id in search_res.ids:
        pageranks.append(search_res.field[chunk_id].get(PAGERANK_FLD, 0))
    pageranks = np.array(pageranks, dtype=float)

    if not query_rfea:
        return np.array([0 for _ in range(len(search_res.ids))]) + pageranks

    # 计算标签特征相似度
    q_denor = np.sqrt(np.sum([s*s for t,s in query_rfea.items() if t != PAGERANK_FLD]))
    for i in search_res.ids:
        nor, denor = 0, 0
        if not search_res.field[i].get(TAG_FLD):
            rank_fea.append(0)
            continue
        for t, sc in eval(search_res.field[i].get(TAG_FLD, "{}")).items():
            if t in query_rfea:
                nor += query_rfea[t] * sc
            denor += sc * sc
        if denor == 0:
            rank_fea.append(0)
        else:
            rank_fea.append(nor/np.sqrt(denor)/q_denor)

    return np.array(rank_fea)*10. + pageranks
```

### 5.2 Rank Feature生成

Rank Feature通过 `label_question()` 函数生成，为查询打上标签特征，用于与chunk的标签进行匹配。

## 6. 与初始检索的融合策略

### 6.1 检索流程

1. **初始检索**: 从Elasticsearch/Infinity检索 `RERANK_LIMIT` 条结果
2. **重排序**: 对所有结果进行重排序
3. **阈值过滤**: 过滤掉低于 `similarity_threshold` 的结果
4. **分页**: 返回对应页面的结果

### 6.2 代码流程

```python
# 1. 初始检索
sres = self.search(req, [index_name(tid) for tid in tenant_ids], kb_ids, embd_mdl, highlight, rank_feature=rank_feature)

# 2. 重排序
if rerank_mdl and sres.total > 0:
    sim, tsim, vsim = self.rerank_by_model(rerank_mdl, sres, question, ...)
else:
    if settings.DOC_ENGINE_INFINITY:
        # Infinity已归一化，直接使用评分
        sim = [sres.field[id].get("_score", 0.0) for id in sres.ids]
    else:
        # ElasticSearch需要本地重排序
        sim, tsim, vsim = self.rerank(sres, question, ...)

# 3. 排序和过滤
sim_np = np.array(sim, dtype=np.float64)
sorted_idx = np.argsort(sim_np * -1)
valid_idx = [int(i) for i in sorted_idx if sim_np[i] >= similarity_threshold]

# 4. 分页返回
page_index = (page - 1) % max_pages
begin = page_index * page_size
end = begin + page_size
page_idx = valid_idx[begin:end]
```

### 6.3 评分融合公式

**最终评分**:
```
final_score = token_similarity * tkweight + vector_similarity * vtweight + rank_feature_score
```

其中:
- `token_similarity`: 基于BM25的文本相似度
- `vector_similarity`: 基于余弦相似度的向量相似度
- `rank_feature_score`: 标签特征和PageRank评分
- `tkweight`: 文本权重（默认0.3，对应 `1 - vector_similarity_weight`）
- `vtweight`: 向量权重（默认0.7，对应 `vector_similarity_weight`）

## 7. 批处理优化

### 7.1 HuggingfaceRerank的批处理

在 [rag/llm/rerank_model.py:390-408](../../../rag/llm/rerank_model.py#L390-L408)：

```python
@staticmethod
def post(query: str, texts: list, url="127.0.0.1"):
    exc = None
    scores = [0 for _ in range(len(texts))]
    batch_size = 8  # 批处理大小为8
    for i in range(0, len(texts), batch_size):
        try:
            res = requests.post(
                f"http://{url}/rerank",
                headers={"Content-Type": "application/json"},
                json={
                    "query": query,
                    "texts": texts[i : i + batch_size],  # 批量处理
                    "raw_scores": False,
                    "truncate": True
                }
            )
            for o in res.json():
                scores[o["index"] + i] = o["score"]
        except Exception as e:
            exc = e

    if exc:
        raise exc
    return np.array(scores)
```

## 8. 评分归一化

部分模型实现了评分归一化处理：

```python
# LocalAIRerank和OpenAI_APIRerank的归一化
min_rank = np.min(rank)
max_rank = np.max(rank)

# 避免除以零
if not np.isclose(min_rank, max_rank, atol=1e-3):
    rank = (rank - min_rank) / (max_rank - min_rank)
else:
    rank = np.zeros_like(rank)
```

## 10. 性能考虑

1. **RERANK_LIMIT限制**: 默认约64条结果进行重排序，平衡性能和效果
2. **批处理**: HuggingfaceRerank使用批处理大小8
3. **模型选择**: 不同模型的性能和效果不同，可根据需求选择
4. **Token截断**: 避免处理过长文本，提高效率

## 11. 总结

RAGFlow的重排序机制提供了以下特性：

1. **多模型支持**: 支持15+种Rerank模型
2. **灵活配置**: 可选择使用Rerank模型或本地重排序
3. **多维度评分**: 融合向量、文本和rank feature三种评分
4. **批处理优化**: 提高处理效率
5. **阈值过滤**: 确保返回结果的相关性质量

重排序是提高RAG系统效果的关键环节，合理配置重排序模型和参数可以显著提升用户满意度。
