```python
def _extract_table_figure(self, need_image, ZM, return_html, need_position, separate_tables_figures=False):
    """
    从文本框中提取表格和图片，并进行图文分离处理

    参数:
        need_image (bool): 是否需要提取图像
```

## 二、业务逻辑

### A. 核心目标

**图文分离与结构化提取**

将OCR识别的文本框按照内容类型分离为：
1. **表格（tables）**: 需要结构化提取，生成HTML/文本
2. **图片（figures）**: 需要裁剪图像，添加描述文本
3. **普通文本（boxes）**: 保留在boxes列表中

### B. 输入依赖

| 依赖项 | 来源 | 用途 |
|--------|------|------|
| `self.boxes` | `_text_merge()` 等 | OCR文本框列表，包含layout_type |
| `self.page_layout` | `_layouts_rec()` | 版面布局信息，用于优化裁剪边界 |
| `self.page_images` | `__images__()` | 页面图像，用于裁剪表格/图片 |
| `self.page_cum_height` | `__images__()` | 跨页累积高度，用于坐标计算 |
| `self.tbl_det` | `__init__()` | TableStructureRecognizer，用于构建表格 |

### 步骤2: 跨页表格合并（[pdf_parser.py:910-929](pdf_parser.py#L910-L929)）

```python
# 记录不可合并的layout
nomerge_lout_no = set(nomerge_lout_no)

# 按位置排序
tbls = sorted([(k, bxs) for k, bxs in tables.items()], key=lambda x: (x[1][0]["top"], x[1][0]["x0"]))

# 从后向前遍历
i = len(tbls) - 1
while i - 1 >= 0:
    k0, bxs0 = tbls[i - 1]  # 上一个表格
    k, bxs = tbls[i]        # 当前表格
    i -= 1

    # 检查1: 上一个表格不可合并
    if k0 in nomerge_lout_no:
        continue

    # 检查2: 在同一页
    if bxs[0]["page_number"] == bxs0[0]["page_number"]:
        continue

    # 检查3: 跨页超过1页
    if bxs[0]["page_number"] - bxs0[0]["page_number"] > 1:
        continue

    # 检查4: Y轴距离过大
    mh = self.mean_height[bxs[0]["page_number"] - 1]
    if self._y_dis(bxs0[-1], bxs[0]) > mh * 23:
        continue

    # 合并表格
    tables[k0].extend(tables[k])
    del tables[k]
```

### 步骤3: 标题匹配（[pdf_parser.py:934-971](pdf_parser.py#L934-L971)）

```python
def x_overlapped(a, b):
    """判断两个框在X轴上是否有重叠"""
    return not any([a["x1"] < b["x0"], a["x0"] > b["x1"]])

# 遍历剩余的boxes（主要是caption）
i = 0
while i < len(self.boxes):
    c = self.boxes[i]

    # 只处理caption
    if not TableStructureRecognizer.is_caption(c):
        i += 1
        continue

    # 寻找最近的表格/图片
    def nearest(tbls):
        nonlocal c
        mink = ""
        minv = 1000000000
        for k, bxs in tbls.items():
            for b in bxs:
                # 跳过caption本身
                if b.get("layout_type", "").find("caption") >= 0:
                    continue

                # 计算距离
                y_dis = self._y_dis(c, b)
                x_dis = self._x_dis(c, b) if not x_overlapped(c, b) else 0
                dis = y_dis * y_dis + x_dis * x_dis  # 欧氏距离

                if dis < minv:
                    mink = k
                    minv = dis
        return mink, minv

    # 找到最近的表格和图片
    tk, tv = nearest(tables)    # 表格距离
    fk, fv = nearest(figures)   # 图片距离

    # 优先匹配距离更近的
    if tv < fv and tk:
        tables[tk].insert(0, c)  # 插入到表格列表的开头
        logging.debug("TABLE:" + self.boxes[i]["text"] + "; Cap: " + tk)
    elif fk:
        figures[fk].insert(0, c)  # 插入到图片列表的开头
        logging.debug("FIGURE:" + self.boxes[i]["text"] + "; Cap: " + tk)

    self.boxes.pop(i)  # 从boxes中移除
```

### 步骤4: 图像裁剪（[pdf_parser.py:973-1005](pdf_parser.py#L973-L1005)）

```python
def cropout(bxs, ltype, poss):
    """
    裁剪表格/图片的图像区域

    参数:
        bxs: 文本框列表
        ltype: layout类型（"table" 或 "figure"）
        poss: 位置列表（传出参数）

    返回:
        PIL.Image: 裁剪后的图像
    """
    nonlocal ZM
    pn = set([b["page_number"] - 1 for b in bxs])

    # 情况1: 单页
    if len(pn) < 2:
        pn = list(pn)[0]
        ht = self.page_cum_height[pn]

        # 计算边界框
        b = {
            "x0": np.min([b["x0"] for b in bxs]),
            "top": np.min([b["top"] for b in bxs]) - ht,
            "x1": np.max([b["x1"] for b in bxs]),
            "bottom": np.max([b["bottom"] for b in bxs]) - ht
        }

        # 使用page_layout优化边界
        louts = [layout for layout in self.page_layout[pn] if layout["type"] == ltype]
        ii = Recognizer.find_overlapped(b, louts, naive=True)
        if ii is not None:
            b = louts[ii]

        left, top, right, bott = b["x0"], b["top"], b["x1"], b["bottom"]
        if right < left:
            right = left + 1

        poss.append((pn + self.page_from, left, right, top, bott))
        return self.page_images[pn].crop((left * ZM, top * ZM, right * ZM, bott * ZM))

    # 情况2: 跨页（拼接多页图像）
    pn = {}
    for b in bxs:
        p = b["page_number"] - 1
        if p not in pn:
            pn[p] = []
        pn[p].append(b)

    pn = sorted(pn.items(), key=lambda x: x[0])  # 按页码排序

    # 递归裁剪每一页
    imgs = [cropout(arr, ltype, poss) for p, arr in pn]

    # 拼接图像
    pic = Image.new("RGB",
                     (int(np.max([i.size[0] for i in imgs])),
                      int(np.sum([m.size[1] for m in imgs]))),
                     (245, 245, 245))  # 灰色背景

    height = 0
    for img in imgs:
        pic.paste(img, (0, int(height)))
        height += img.size[1]

    return pic
```

### B. 跨页合并的条件

| 条件 | 说明 | 代码 |
|------|------|------|
| **不可合并标记** | 不在有标题/引用的layout合并 | `k0 in nomerge_lout_no` |
| **跨页** | 必须在不同页 | `page_number != page_number0` |
| **相邻页** | 页码差值 = 1 | `page_number - page_number0 <= 1` |
| **Y轴距离** | 距离不太远 | `y_dis < mean_height * 23` |

**为什么是23？**
- 23行 ≈ 2-3cm
- 经验值：如果跨页表格的Y轴距离超过23行，通常不是同一个表格

---

### C. 标题匹配的距离计算

```python
y_dis = self._y_dis(c, b)
x_dis = self._x_dis(c, b) if not x_overlapped(c, b) else 0
dis = y_dis * y_dis + x_dis * x_dis  # 欧氏距离的平方
```

**几何意义**：

```
Caption (c)          Table (b)
┌───────────┐         ┌───────────┐
│ 表1说明   │         │ 表格内容   │
└───────────┘         └───────────┘
     ↑                     ↑
   (x0, top)            (x0, top)

y_dis = (top_b + bottom_b - top_c - bottom_c) / 2
       ≈ 垂直距离

x_dis = min(
    |x1_c - x0_b|,  # Caption右边界到Table左边界
    |x0_c - x1_b|,  # Caption左边界到Table右边界
    |中心X_c - 中心X_b|  # 中心点距离
)

dis = y_dis² + x_dis²
```

**为什么使用欧氏距离？**
- 同时考虑水平和垂直距离
- 优先匹配垂直距离近的（因为caption通常在表格上方/下方）


### E. 跨页图像拼接

```python
# 创建空白画布
pic = Image.new("RGB",
                 (int(np.max([i.size[0] for i in imgs])),  # 最大宽度
                  int(np.sum([m.size[1] for m in imgs]))),  # 总高度（累加）
                 (245, 245, 245))  # 灰色背景

# 垂直拼接
height = 0
for img in imgs:
    pic.paste(img, (0, int(height)))
    height += img.size[1]
```

**特点**：
- 使用最大宽度（避免裁剪）
- 使用累加高度（垂直拼接）
- 灰色背景（245, 245, 245）

### A. 表格未提取

### B. 图像未裁剪

## 八、总结

### 核心功能

`_extract_table_figure` 是**图文分离与结构化提取**的核心方法：

1. ✅ **图文分离**: 从boxes中提取表格和图片
2. ✅ **跨页合并**: 合并跨页的表格
3. ✅ **标题匹配**: 将caption匹配到对应的表格/图片
4. ✅ **图像裁剪**: 裁剪表格/图片的图像区域
5. ✅ **表格构建**: 使用TableStructureRecognizer构建表格

### 技术亮点

| 特性 | 说明 |
|------|------|
| **智能分离** | 基于layout_type自动分离 |
| **跨页处理** | 合并跨页表格，拼接跨页图像 |
| **标题匹配** | 使用欧氏距离匹配caption |
| **边界优化** | 使用page_layout优化裁剪边界 |
| **多格式支持** | HTML和纯文本格式 |
| **鲁棒性** | 过滤无关文本，处理边界情况 |

### 在解析流程中的位置

```
PDF文档
    ↓
OCR识别 (__images__)
    ↓
版面识别 (_layouts_rec)
    ↓
表格识别 (_table_transformer_job)
    ↓
文本合并 (_text_merge / _naive_vertical_merge)
    ↓
图文分离 (_extract_table_figure) ← 当前方法
    ↓
过滤 scraps (__filterout_scraps)
    ↓
输出结构化结果
```

### 关键参数总结

| 参数 | 作用 | 默认值 |
|------|------|--------|
| **need_image** | 是否提取图像 | True（在parse_into_bboxes中） |
| **ZM** | 缩放倍数 | 3 |
| **return_html** | 是否返回HTML | True |
| **need_position** | 是否返回位置 | True |
| **separate_tables_figures** | 是否分离表格和图片 | False |
