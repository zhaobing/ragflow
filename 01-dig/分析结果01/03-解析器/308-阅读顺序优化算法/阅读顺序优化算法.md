# 阅读顺序优化算法分析

> **文件位置**: [deepdoc/parser/pdf_parser.py](../../../../../deepdoc/parser/pdf_parser.py)
> **相关方法**:
> - `_concat_downward()` (L698-800) - 垂直方向智能文本合并
> - `_final_reading_order_merge()` (L675-696) - 最终阅读顺序重排

## 1. 业务逻辑概述

### 1.1 核心目标

这两个方法负责解决 PDF 解析后的**文本阅读顺序优化**问题：

1. **`_concat_downward`**: 垂直方向智能合并相邻文本框，构建语义连贯的文本块
2. **`_final_reading_order_merge`**: 按照人类阅读习惯（从上到下、从左到右、多列文档）重新排序所有文本框

### 1.2 应用场景

在 PDF 文档解析中，OCR 和布局识别后会产生大量分散的文本框，这些文本框需要：
- **语义合并**: 将属于同一段落、句子的文本框合并
- **顺序调整**: 确保多列文档、跨页内容的阅读顺序正确
- **结构优化**: 为后续的表格提取、图片识别等提供准确的文本上下文

## 2. `_concat_downward` 方法详解

### 2.1 业务逻辑

**垂直方向智能文本合并**，基于机器学习模型判断上下相邻的文本框是否应该合并成一个段落。

**核心思想**:
- 使用 XGBoost 模型提取 28 维特征，判断两个文本框是否属于同一个语义块
- 通过深度优先搜索 (DFS) 构建文本块树
- 对每个文本块内的内容进行合并

### 2.2 执行流程

```
输入: self.boxes (OCR 识别后的文本框列表)
参数: concat_between_pages (是否允许跨页合并)

流程:
┌─────────────────────────────────────┐
│ 1. 按 Y 轴排序所有文本框            │
│    Recognizer.sort_Y_firstly()      │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│ 2. 计算每个文本框的 "in_row" 特征   │
│    - 统计同一行内的文本框数量        │
│    - 范围: 上下各 12 个文本框        │
│    - 阈值: Y 轴距离 < 平均高度        │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│ 3. 深度优先搜索构建文本块            │
│    dfs(up_box, start_index)         │
│    - 从第一个文本框开始              │
│    - 向下查找可合并的文本框          │
│    - 使用 XGBoost 模型判断           │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│ 4. 合并文本块内的内容                │
│    - 合并文本字段                    │
│    - 调整边界坐标 (x0, x1, bottom)   │
│    - 处理英文单词间的空格            │
└─────────────────────────────────────┘
              ↓
输出: 合并后的文本框列表
```

### 2.3 关键技术点

#### 2.3.1 行内文本框统计 (`in_row` 特征)

```python
for i in range(len(self.boxes)):
    mh = self.mean_height[self.boxes[i]["page_number"] - 1]
    self.boxes[i]["in_row"] = 0
    j = max(0, i - 12)
    while j < min(i + 12, len(self.boxes)):
        if j == i:
            j += 1
            continue
        ydis = self._y_dis(self.boxes[i], self.boxes[j]) / mh
        if abs(ydis) < 1:  # Y 轴距离 < 平均高度
            self.boxes[i]["in_row"] += 1
        elif ydis > 0:
            break
        j += 1
```

**作用**: 统计每个文本框周围同一行内有多少个文本框，作为后续合并决策的特征。

#### 2.3.2 XGBoost 模型特征提取

在 L137-180 定义的 `_updown_concat_features()` 方法提取 **28 维特征**：

```python
fea = [
    up.get("R", -1) == down.get("R", -1),           # 1. 是否在同一表格行
    y_dis / h,                                       # 2. Y 轴归一化距离
    down["page_number"] - up["page_number"],         # 3. 页码差
    up["layout_type"] == down["layout_type"],        # 4. 布局类型相同
    up["layout_type"] == "text",                     # 5. 上框是文本
    down["layout_type"] == "text",                   # 6. 下框是文本
    up["layout_type"] == "table",                    # 7. 上框是表格
    down["layout_type"] == "table",                  # 8. 下框是表格
    True if re.search(r"([。？！；!?+)）)]", up["text"]) else False,  # 9. 上框以句号结尾
    True if re.search(r"[，："0-9（+-]$", up["text"]) else False,    # 10. 上框以逗号结尾
    # ... 共 28 个特征
]
```

**模型文件**: `rag/res/deepdoc/updown_concat_xgb.model`
**预测阈值**: `> 0.5` 则合并

#### 2.3.3 深度优先搜索 (DFS) 合并

```python
def dfs(up, dp):
    chunks.append(up)
    i = dp
    while i < min(dp + 12, len(boxes)):
        ydis = self._y_dis(up, boxes[i])
        smpg = up["page_number"] == boxes[i]["page_number"]
        mh = self.mean_height[up["page_number"] - 1]
        mw = self.mean_width[up["page_number"] - 1]

        # 同页距离限制: 4 倍平均高度
        if smpg and ydis > mh * 4:
            break
        # 跨页距离限制: 16 倍平均高度
        if not smpg and ydis > mh * 16:
            break

        down = boxes[i]

        # 表格行约束
        if up.get("R", "") != down.get("R", "") and up["text"][-1] != "，":
            i += 1
            continue

        # 水平位置约束
        if up["x1"] < down["x0"] - 10 * mw or up["x0"] > down["x1"] + 10 * mw:
            i += 1
            continue

        # 特征提取 + 模型预测
        fea = self._updown_concat_features(up, down)
        if self.updown_cnt_mdl.predict(xgb.DMatrix([fea]))[0] <= 0.5:
            i += 1
            continue

        dfs(down, i + 1)
        boxes.pop(i)
        return
```

**关键参数**:
- 搜索范围: 向下最多 12 个文本框
- 同页距离阈值: `mean_height * 4`
- 跨页距离阈值: `mean_height * 16`
- 水平重叠阈值: `mean_width * 10`

#### 2.3.4 文本块内合并

```python
for b in blocks:
    if len(b) == 1:
        boxes.append(b[0])
        continue
    t = b[0]
    for c in b[1:]:
        t["text"] = t["text"].strip()
        c["text"] = c["text"].strip()
        if not c["text"]:
            continue
        # 英文单词间添加空格
        if t["text"] and re.match(r"[0-9\.a-zA-Z]+$", t["text"][-1] + c["text"][-1]):
            t["text"] += " "
        t["text"] += c["text"]
        t["x0"] = min(t["x0"], c["x0"])
        t["x1"] = max(t["x1"], c["x1"])
        t["page_number"] = min(t["page_number"], c["page_number"])
        t["bottom"] = c["bottom"]
```

## 3. `_final_reading_order_merge` 方法详解

### 3.1 业务逻辑

**最终阅读顺序重排**，按照人类阅读习惯对文本框进行全局排序。

**核心思想**:
- 先按列分组（基于 `_assign_column` 的 KMeans 聚类结果）
- 再按页码、列号、Y 轴坐标排序

### 3.2 执行流程

```
输入: self.boxes (已合并的文本框列表)
参数: zoomin (缩放倍数)

流程:
┌─────────────────────────────────────┐
│ 1. 为文本框分配列 ID                 │
│    self._assign_column()            │
│    - 使用 KMeans 聚类识别列数        │
│    - 为每个文本框标记 col_id         │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│ 2. 按页码和列号分组                  │
│    pages[page_number][col_id]       │
│    = [box1, box2, ...]              │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│ 3. 每页每列内部排序                  │
│    key = (top, x0)                  │
│    - 先按 Y 轴坐标 (top) 排序        │
│    - 再按 X 轴坐标 (x0) 排序        │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│ 4. 全局重组                          │
│    for page in sorted(pages):       │
│      for col in sorted(cols):       │
│        new_boxes.extend(cols)       │
└─────────────────────────────────────┘
              ↓
输出: 按阅读顺序排列的文本框列表
```

### 3.3 关键技术点

#### 3.3.1 列分配 (`_assign_column`)

在 L447-541 实现，使用 KMeans 聚类识别文档列数：

```python
# 提取左边界
x0s_raw = np.array([b["x0"] for b in bxs], dtype=float)

# 缩进归一化（12% 容差）
INDENT_TOL = width * 0.12
x0s = []
for x in x0s_raw:
    if abs(x - min_x0) < INDENT_TOL:
        x0s.append([min_x0])
    else:
        x0s.append([x])

# 尝试 1-4 列
for k in range(1, max_try + 1):
    km = KMeans(n_clusters=k, n_init="auto")
    labels = km.fit_predict(x0s)
    score = silhouette_score(x0s, labels)  # 轮廓系数
    if score > best_score:
        best_score = score
        best_k = k
```

**关键参数**:
- 最大列数: 4
- 缩进容差: 页面宽度的 12%
- 评估指标: Silhouette Score（轮廓系数）

#### 3.3.2 三层排序规则

```python
# 第一层: 按页码分组
pages = defaultdict(lambda: defaultdict(list))
for b in self.boxes:
    pg = b["page_number"]
    col = b.get("col_id", 0)
    pages[pg][col].append(b)

# 第二层: 每页每列内部排序
for pg in pages:
    for col in pages[pg]:
        pages[pg][col].sort(key=lambda x: (x["top"], x["x0"]))

# 第三层: 全局重组
new_boxes = []
for pg in sorted(pages.keys()):       # 页码升序
    for col in sorted(pages[pg].keys()):  # 列号升序
        new_boxes.extend(pages[pg][col])
```

**排序优先级**: `页码 > 列号 > Y轴坐标 > X轴坐标`

## 6. 算法优缺点分析

### 6.1 `_concat_downward` 优点

1. **语义感知**: 使用机器学习模型，能识别复杂的文本合并场景
2. **多特征融合**: 综合考虑布局、位置、标点、语言等 28 维特征
3. **跨页支持**: 可处理跨页的段落合并
4. **表格感知**: 通过 `R` (row) 特征避免破坏表格结构

### 6.2 `_concat_downward` 缺点

1. **计算复杂度高**: DFS + 模型预测，时间复杂度 O(n²)
2. **依赖模型质量**: 需要训练好的 XGBoost 模型
3. **参数敏感**: 距离阈值、搜索范围需要根据文档类型调整
4. **当前未启用**: 代码中直接 return，可能存在性能或准确性问题

### 6.3 `_final_reading_order_merge` 优点

1. **简单高效**: 纯排序操作，时间复杂度 O(n log n)
2. **符合阅读习惯**: 严格遵循从上到下、从左到右的顺序
3. **多列支持**: 自动识别单列、双列、三列等布局

### 6.4 `_final_reading_order_merge` 缺点

1. **依赖列识别**: KMeans 聚类对复杂布局可能误判
2. **缺乏语义理解**: 纯几何排序，可能打断语义连贯性
3. **跨列处理弱**: 无法处理跨列的标题、图表等元素

---

## 7. 总结

### 7.1 核心价值

这两个方法共同构成了 RAGFlow PDF 解析流程中的**阅读顺序优化层**：

- **`_concat_downward`**: 语义层优化，确保文本块内部的语义连贯性
- **`_final_reading_order_merge`**: 几何层优化，确保全局阅读顺序的正确性

### 7.2 技术亮点

1. **机器学习 + 规则引擎**: XGBoost 模型与启发式规则相结合
2. **多阶段处理**: 先语义合并、后几何排序，层次清晰
3. **自适应性强**: 通过轮廓系数自动识别列数，无需手动配置

### 7.3 改进方向

1. **性能优化**: 对 `_concat_downward` 进行并行化处理
2. **模型迭代**: 收集更多场景数据，提升 XGBoost 模型准确性
3. **规则增强**: 引入更多文档结构特征（如段落缩进、列表标记等）
4. **配置化**: 将硬编码的参数（距离阈值、搜索范围）改为可配置项
