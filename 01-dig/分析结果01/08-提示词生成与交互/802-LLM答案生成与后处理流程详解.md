## 二、动态调整 max_tokens

### 2.1 代码逻辑

```python
# dialog_service.py:511-513

if "max_tokens" in gen_conf:
    gen_conf["max_tokens"] = min(gen_conf["max_tokens"], max_tokens - used_token_count)
```

### 2.2 计算逻辑

```
实际输出上限 = min(配置值, 模型最大token - 已使用token)

示例：
- 模型最大上下文: 8192 tokens
- 已使用输入: 3000 tokens
- 配置的 max_tokens: 4096 tokens

gen_conf["max_tokens"] = min(4096, 8192 - 3000)
                          = min(4096, 5192)
                          = 4096
```

### 2.3 设计目的

1. **防止超限**: 避免输入 + 输出总 token 超过模型上下文窗口
2. **充分利用**: 根据实际输入动态调整输出预算
3. **配置优先**: 在安全范围内优先使用用户配置的值

**判断逻辑**:

| 条件 | 策略 | 说明 |
|------|------|------|
| `embd_mdl` 存在且答案无 `[ID:X]` | 自动插入 | 通过向量相似度智能插入引用 |
| `embd_mdl` 不存在或有 `[ID:X]` | 手动提取 | LLM 已插入引用，只需提取并验证 |

### 5.3 insert_citations 方法详解

**位置**: [rag/nlp/search.py:204-291](../../rag/nlp/search.py#L204-L291)

**核心逻辑**:

```python
def insert_citations(self, answer, chunks, chunk_v,
                   embd_mdl, tkweight=0.1, vtweight=0.9):
    """
    参数:
    - answer: LLM 生成的答案
    - chunks: 知识块内容列表
    - chunk_v: 知识块向量列表
    - embd_mdl: 嵌入模型
    - tkweight: 词相似度权重 (0-1)
    - vtweight: 向量相似度权重 (0-1)

    返回:
    - 插入引用的答案
    - 引用的 chunk 索引集合
    """
```

**处理流程**:

1. **答案分片**:
   - 按句子分隔符分割: `[；。？！\n]` 或 `[a-z][.?!;][ \n]`
   - 保护代码块 (```` ````) 不被分割

2. **向量编码**:
   ```python
   ans_v, _ = embd_mdl.encode(pieces_)
   ```

3. **相似度计算**:
   ```python
   for i, a in enumerate(pieces_):
       sim, tksim, vtsim = self.qryr.hybrid_similarity(
           ans_v[i],           # 答案句子向量
           chunk_v,             # 知识块向量列表
           tokens,              # 答案句子分词
           chunks_tks,           # 知识块分词
           tkweight, vtweight   # 混合权重
       )
       mx = np.max(sim) * 0.99  # 最大相似度 * 0.99
       if mx >= thr:
           cites[idx[i]] = [ii for ii in range(len(chunk_v)) if sim[ii] > mx][:4]
   ```

4. **引用插入**:
   ```python
   for i, p in enumerate(pieces):
       res += p
       if i in cites and i in cites[i]:
           for c in cites[i]:
               if c not in seted:
                   res += f" [ID:{c}]"
                   seted.add(c)
   ```

**相似度阈值**:
- 初始: `0.63`
- 递减: 每轮 `* 0.8`
- 下限: `0.3`
- 每个句子最多引用 4 个知识块

## 六、引用格式修复

### 6.1 修复需求

LLM 可能使用各种引用格式，需要统一为 `[ID:X]` 格式。

### 6.2 坏格式模式

```python
# dialog_service.py:244-249
BAD_CITATION_PATTERNS = [
    re.compile(r"\(\s*ID\s*[: ]*\s*(\d+)\s*\)"),  # (ID: 12)
    re.compile(r"\[\s*ID\s*[: ]*\s*(\d+)\s*\]"),  # [ID: 12]
    re.compile(r"【\s*ID\s*[: ]*\s*(\d+)\s*】"),  # 【ID: 12】
    re.compile(r"ref\s*(\d+)", flags=re.IGNORECASE),  # ref12、REF 12
]
```

### 6.3 repair_bad_citation_formats 函数

```python
# dialog_service.py:252-278
def repair_bad_citation_formats(answer: str, kbinfos: dict, idx: set):
    """
    修复各种引用格式为标准 [ID:X] 格式

    参数:
    - answer: 答案文本
    - kbinfos: 包含 chunks 的检索结果
    - idx: 当前已识别的引用索引集合

    返回:
    - 修复后的答案
    - 更新后的索引集合
    """
    max_index = len(kbinfos["chunks"])

    def safe_add(i):
        if 0 <= i < max_index:
            idx.add(i)
            return True
        return False

    def find_and_replace(pattern, group_index=1, ...):
        for pattern in BAD_CITATION_PATTERNS:
            find_and_replace(pattern)

    return answer, idx
```

**修复示例**:

```python

answer = "根据文档 (ID:1)，产品价格是2999元。"

# 输出
answer = "根据文档 [ID:1]，产品价格是2999元。"
idx = {1}
```

3. **TTS 实时转换**: 增量文本转为音频
4. **最终装饰**: 最后一次 yield 包含完整引用和统计

## 十一、TTS 文字转语音

### 11.1 tts 函数

**位置**: [dialog_service.py:802-815](../../api/db/services/dialog_service.py#L802-L815)

```python
def tts(tts_mdl, text):
    if not tts_mdl or not text:
        return None
    text = clean_tts_text(text)
    if not text:
        return None
    bin = b""
    try:
        for chunk in tts_mdl.tts(text):
            bin += chunk
    except Exception as e:
        logging.error(f"TTS failed: {e}, text={text!r}")
        return None
    return binascii.hexlify(bin).decode("utf-8")
```

### 11.2 clean_tts_text 函数

**位置**: [dialog_service.py:773-800](../../api/db/services/dialog_service.py#L773-L800)

```python
def clean_tts_text(text: str) -> str:
    if not text:
        return ""

    # 1. 编码清理
    text = text.encode("utf-8", "ignore").decode("utf-8", "ignore")

    # 2. 移除控制字符
    text = re.sub(r"[\x00-\x08\x0B-\x0C\x0E-\x1F\x7F]", "", text)

    # 3. 移除 emoji
    emoji_pattern = re.compile(
        "[\U0001F600-\U0001F64F"
        "\U0001F300-\U0001F5FF"
        "\U0001F680-\U0001F6FF"
        "\U0001F1E0-\U0001F1FF"
        "\U00002700-\U000027BF"
        "\U0001F900-\U0001F9FF"
        "\U0001FA70-\U0001FAFF]+",
        flags=re.UNICODE
    )
    text = emoji_pattern.sub("", text)

    # 4. 规范化空白
    text = re.sub(r"\s+", " ", text).strip()

    # 5. 长度限制
    MAX_LEN = 500
    if len(text) > MAX_LEN:
        text = text[:MAX_LEN]

    return text
```

**清理步骤**:
1. **编码修正**: 移除无效 UTF-8 字符
2. **控制字符移除**: ASCII 控制字符
3. **Emoji 移除**: Unicode 范围匹配
4. **空白规范**: 多个空白合并为单个空格
5. **长度限制**: 最多 500 字符

```python
    langfuse_output = "\n" + re.sub(r"^.*?(### Query:.*)", r"\1", prompt, flags=re.DOTALL)
    langfuse_output = {
        "time_elapsed:": re.sub(r"\n", "  \n", langfuse_output),
        "created_at": time.time()
    }
    langfuse_generation.update(output=langfuse_output)
    langfuse_generation.end()
```

### 12.2 输出格式化

```python
langfuse_output = "\n" + re.sub(r"^.*?(### Query:.*)", r"\1", prompt, flags=re.DOTALL)
```

**正则解释**: `^.*?(### Query:.*)`
- `^.*?`: 非贪婪匹配开头任意字符
- `(### Query:.*)`: 捕获及 "Query:" 到结尾

**效果**: 只保留 prompt 中从 "### Query:" 开始的部分

## 十五、优化建议与最佳实践

### 15.1 引用准确性优化

**当前问题**: 自动插入依赖向量相似度，可能误引用

**优化方向**:
1. **结合重排序**: 使用 rerank 分数加权
2. **多候选投票**: 每个句子引用多个相似块
3. **上下文感知**: 考虑前后句子的引用关系

### 15.2 性能优化

**当前实现**:
- 每次 decorate_answer 都深拷贝 kbinfos

**优化建议**:
- 只深拷贝需要的字段
- 使用 `copy.deepcopy` 的替代方案 (如 `pickle`)

### 15.3 错误处理增强

**当前实现**:
- 只检测 "invalid key" 和 "invalid api"

**建议扩展**:
```python
ERROR_PATTERNS = [
    "invalid key",
    "invalid api",
    "rate limit",
    "insufficient quota",
    "model not found"
]
```

| 职责 | 实现方式 | 代码位置 |

1. **灵活的引用模式**: 支持自动插入和手动引用
