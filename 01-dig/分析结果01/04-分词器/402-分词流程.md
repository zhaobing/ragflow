**核心功能**: 将输入文本（中英文混合）进行分词处理，返回空格分隔的词序列。

## 二、业务逻辑

`tokenize` 方法是 RAGFlow 分词器的核心入口，负责：

1. **文本预处理**: 全角转半角、大写转小写、繁体转简体
2. **语言分离**: 将中英文混合文本按语言类型分段
3. **双向分词**: 对中文同时执行正向和逆向最大匹配
4. **结果融合**: 智能合并双向分词结果，处理歧义
5. **后处理优化**: 合并被错误分割的词

```python
def _split_by_lang(self, line):
    # 1. 按 SPLIT_CHAR 分割
    arr = re.split(self.SPLIT_CHAR, line)

    # 2. 对每段内部进行语言检测
    for segment in arr:
        s = 0
        while s < len(segment):
            e = s + 1
            # 判断首字符语言类型
            zh = is_chinese(segment[s])

            # 扩展直到语言类型变化
            while e < len(segment):
                _zh = is_chinese(segment[e])
                if _zh == zh:
                    e += 1  # 语言类型相同，继续扩展
                else:
                    break   # 语言类型变化，停止

            txt_lang_pairs.append((segment[s:e], zh))
            s = e
    return txt_lang_pairs
```

```python
def is_chinese(s):
    # Unicode 中日韩统一表意文字范围: U+4E00 - U+9FA5
    if s >= "\u4e00" and s <= "\u9fa5":
        return True
    else:
        return False
```

**正向最大匹配 (_max_forward)** ([line 290-311](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L290-L311)):

```python
def _max_forward(self, line):
    res = []
    s = 0
    while s < len(line):
        e = s + 1
        t = line[s:e]

        # 尝试扩展到最长匹配词
        while e < len(line) and self.trie_.has_keys_with_prefix(self.key_(t)):
            e += 1
            t = line[s:e]

        # 回退到词典中的词
        while e - 1 > s and self.key_(t) not in self.trie_:
            e -= 1
            t = line[s:e]

        # 添加到结果
        if self.key_(t) in self.trie_:
            res.append((t, self.trie_[self.key_(t)]))
        else:
            res.append((t, (0, "")))  # 未登录词

        s = e

    return self.score_(res)
```

**逆向最大匹配 (_max_backward)** ([line 313-334](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L313-L334)):

```python
def _max_backward(self, line):
    res = []
    s = len(line) - 1  # 从末尾开始
    while s >= 0:
        e = s + 1
        t = line[s:e]

        # 向左扩展（使用反向索引）
        while s > 0 and self.trie_.has_keys_with_prefix(self.rkey_(t)):
            s -= 1
            t = line[s:e]

        # 回退
        while s + 1 < e and self.key_(t) not in self.trie_:
            s += 1
            t = line[s:e]

        res.append((t, self.trie_[self.key_(t)]))
        s -= 1

    # 反转结果（因为是从右往左添加的）
    return self.score_(res[::-1])
```

##### 3.4 DFS歧义消解

**dfs_ 深度优先搜索** ([line 160-239](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L160-L239)):

```python
def dfs_(self, chars, s, preTks, tkslist, _depth=0, _memo=None):
    """
    chars: 字符数组
    s: 当前位置
    preTks: 已分词的词列表
    tkslist: 存储所有可能的分词方案
    _memo: 记忆化缓存
    """
    MAX_DEPTH = 10
    if _depth > MAX_DEPTH:
        # 深度超限，强制完成
        tkslist.append(preTks + [(remaining, (-12, ""))])
        return s

    # 记忆化检查
    state_key = (s, tuple(tk[0] for tk in preTks))
    if state_key in _memo:
        return _memo[state_key]

    # 处理重复字符 (如 "!!!!!!")
    if is_repetitive(chars[s:s+5]):
        # 最多取10个重复字符
        end = min(s + 10, len(chars))
        tkslist.append(preTks + [(chars[s:end], (0, ""))])
        return end

    # 尝试所有可能的词
    for e in range(s + 1, len(chars) + 1):
        t = "".join(chars[s:e])
        k = self.key_(t)

        # 前缀检查
        if e > s + 1 and not self.trie_.has_keys_with_prefix(k):
            break  # 没有以此开头的词，停止扩展

        # 完整词检查
        if k in self.trie_:
            # 递归处理剩余部分
            self.dfs_(chars, e, preTks + [(t, self.trie_[k])], tkslist, _depth + 1, _memo)

    # 单字回退（处理未登录词）
    t = chars[s]
    if t not in self.trie_:
        self.dfs_(chars, s + 1, preTks + [(t, (-12, ""))], tkslist, _depth + 1, _memo)
```

**评分公式** ([line 253-263](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L253-L263)):

```python
def score_(self, tfts):
    B = 30  # 基础分
    F = 0   # 总词频
    L = 0   # 长词数

    for tk, (freq, tag) in tfts:
        F += freq                # 累加词频
        L += 0 if len(tk) < 2 else 1  # 统计长度≥2的词

    L /= len(tfts)  # 长词比例

    # 最终评分 = 基础分 + 词频分 + 长词分
    return B / len(tfts) + L + F
```

**merge_ 合并优化** ([line 272-288](../../../../../.venv/lib/python3.12/site-packages/infinity/rag_tokenizer.py#L272-L288)):

```python
def merge_(self, tks):
    """
    合并被错误分割的词
    例如: "机器 学习" → "机器学习" (如果"机器学习"在词典中)
    """
    res = []
    tks = re.sub(r"[ ]+", " ", tks).split()
    s = 0
    while s < len(tks):
        E = s + 1
        # 尝试向后合并2-5个词
        for e in range(s + 2, min(len(tks) + 2, s + 6)):
            tk = "".join(tks[s:e])
            # 如果合并后的词在词典中且频率>0
            if re.search(self.SPLIT_CHAR, tk) and self.freq(tk):
                E = e  # 更新结束位置
        res.append("".join(tks[s:E]))
        s = E
    return " ".join(res)
```

```python
词典: {"人工智能": 频率>0, "机器学习": 频率>0}

合并过程:
s=0: "人工 智能" → "人工智能" (在词典) → E=2
s=2: "技术" (不可合并) → E=3
s=3: "机 器 学习" → "机器学习" (在词典) → E=6
s=6: "系统" (不可合并) → E=7
```

## 五、技术要点

### 5.1 双向最大匹配算法

**原理**:
- 正向匹配: 从左到右，优先匹配长词
- 逆向匹配: 从右到左，优先匹配长词
- 结果融合: 比较双向结果，处理差异

**优势**:
- 消除单一方向的贪心策略误差
- 提高未登录词识别准确率
- 减少分词歧义

### 5.2 N-gram与动态规划

**DFS搜索空间**:
```
对于长度为n的文本，最坏情况下需要尝试O(2^n)种分词方案
通过记忆化（memoization）和深度限制，实际复杂度降为O(n * max_word_len)
```

**记忆化缓存**:
```python
state_key = (s, tuple(tk[0] for tk in preTks))
if state_key in _memo:
    return _memo[state_key]
```

### 5.3 评分机制

**评分因子**:
1. **词频分 (F)**: 词典中的词频越高，评分越高
2. **长词分 (L)**: 长词比例越高，评分越高（倾向于少切分）
3. **词数分 (B/len)**: 词数越少，评分越高（倾向于大粒度）

**设计理念**:
```python
评分 = 30/词数 + 长词比例 + 总词频
      ↑          ↑           ↑
   大粒度    语义完整度   常用程度
```

### 5.4 英文NLP处理

**NLTK处理流程**:
```python
word_tokenize          # 分词
    ↓
WordNetLemmatizer     # 词形还原 (running → run)
    ↓
SnowballStemmer       # 词干提取 (studies → studi)
```

**组合优势**:
- 词形还原保证词的完整性
- 词干提取统一不同变形
- 提高英文检索的召回率

### 5.5 性能优化

**优化策略**:
1. **Trie树前缀检查**: `has_keys_with_prefix()` 快速判断是否有匹配词
2. **记忆化缓存**: 避免重复计算相同状态
3. **深度限制**: MAX_DEPTH=10 防止递归过深
4. **贪心回退**: 正向/逆向匹配使用贪心策略，仅在差异处使用DFS

**性能对比**:
```
纯DFS:         O(2^n)  指数级
双向+贪心:     O(n)    线性级
记忆化DFS:     O(n*m)  n=文本长度, m=最大词长
```
