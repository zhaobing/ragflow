# `naive_merge` 方法分析报告

## 一、方法概述

**方法位置**: [rag/nlp/__init__.py:787-843](../../../../../rag/nlp/__init__.py#L787-L843)

**方法签名**:
```python
def naive_merge(sections: str | list, chunk_token_num=128, delimiter="\n。；！？", overlapped_percent=0):
```

**核心功能**: 将多个文本sections按照token数量限制合并成chunks，支持重叠合并以保持上下文连续性。

## 二、业务逻辑

### 2.1 核心功能

`naive_merge` 负责：

1. **智能合并**: 将小段文本合并成指定大小的chunks
2. **Token控制**: 确保每个chunk不超过token限制（默认128）
3. **重叠处理**: 支持chunk间的重叠，保持上下文连续性
4. **位置标记保留**: 保留PDF解析时的位置标签（@@...##格式）
5. **自定义分隔符**: 支持用户自定义的分隔符进行强制分割
6. **短文本过滤**: 过滤掉token数<8的过短内容

### 2.2 输入参数

```python
sections: str | list
  - 字符串: 单个文本块
  - 列表: [(text, position), ...] 或 [text, ...]

chunk_token_num: int = 128
  - 每个chunk的最大token数

delimiter: str = "\n。；！？"
  - 分隔符字符串，用于添加在section之间
  - 支持自定义格式: "`自定义分隔符`默认分隔符"

overlapped_percent: int = 0
  - 重叠百分比（0-90）
  - 例如: 20表示相邻chunk有20%的重叠
```

### 2.3 输出结果

```python
List[str]
  - 合并后的文本chunks列表
  - 每个chunk的token数 <= chunk_token_num
  - 相邻chunk之间有指定的重叠比例
```

#### 步骤2: 解析自定义分隔符 ([line 820-838](../../../../../rag/nlp/__init__.py#L820-L838))

```python
custom_delimiters = [m.group(1) for m in re.finditer(r"`([^`]+)`", delimiter)]
has_custom = bool(custom_delimiters)

if has_custom:
    # 有自定义分隔符，强制分割模式
    custom_pattern = "|".join(re.escape(t) for t in sorted(set(custom_delimiters), key=len, reverse=True))
    cks, tk_nums = [], []
    for sec, pos in sections:
        split_sec = re.split(r"(%s)" % custom_pattern, sec, flags=re.DOTALL)
        for sub_sec in split_sec:
            if re.fullmatch(custom_pattern, sub_sec or ""):
                continue  # 跳过分隔符本身
            text = "\n" + sub_sec
            local_pos = pos
            if num_tokens_from_string(text) < 8:
                local_pos = ""
            if local_pos and text.find(local_pos) < 0:
                text += local_pos
            cks.append(text)
            tk_nums.append(num_tokens_from_string(text))
    return cks
```

##### add_chunk函数 ([line 798-818](../../../../../rag/nlp/__init__.py#L798-L818))

```python
def add_chunk(t, pos):
    nonlocal cks, tk_nums, delimiter

    # 计算token数
    tnum = num_tokens_from_string(t)

    # 处理位置标签
    if not pos:
        pos = ""

    # 过滤短文本
    if tnum < 8:
        pos = ""

    # 判断是否需要新建chunk
    # 条件: 当前chunk为空 OR 当前chunk的token数超过阈值
    threshold = chunk_token_num * (100 - overlapped_percent) / 100
    if cks[-1] == "" or tk_nums[-1] > threshold:
        # ===== 新建chunk =====
        if cks:
            # 计算重叠部分
            overlapped = RAGFlowPdfParser.remove_tag(cks[-1])
            overlap_ratio = overlapped_percent / 100
            overlap_start = int(len(overlapped) * (1 - overlap_ratio))
            t = overlapped[overlap_start:] + t

        # 添加位置标签（如果不存在）
        if t.find(pos) < 0:
            t += pos

        cks.append(t)
        tk_nums.append(tnum)
    else:
        # ===== 追加到当前chunk =====
        if cks[-1].find(pos) < 0:
            t += pos
        cks[-1] += t
        tk_nums[-1] += tnum
```

**重叠计算详解**:

```python
overlapped_percent = 20  # 20%重叠

当前chunk: "这是一段很长的文本内容，包含了很多重要信息。"
           ↓
去除标签: "这是一段很长的文本内容，包含了很多重要信息。"
           ↓
长度: 24个字符

重叠部分:
  overlap_start = int(24 * (100-20)/100) = int(24 * 0.8) = 19
  overlapped[19:] = "包含了很多重要信息。"

新chunk = "包含了很多重要信息。" + "新添加的文本内容"
```

**位置标签处理**:

```python

    text += pos

结果: "这是段落内容@@1\t100\t500\t0\t200##"
```

## 五、技术要点

### 5.1 Token计数

```python
tnum = num_tokens_from_string(t)
```

**num_tokens_from_string** 实现原理:
```python
# 使用tiktoken库（GPT tokenizer）
import tiktoken
encoder = tiktoken.get_encoding("cl100k_base")

def num_tokens_from_string(text):
    return len(encoder.encode(text))
```

**示例**:
```python
text = "Hello, 世界!"
tokens = encoder.encode(text)
# → [9906, 11, 3403, 0]
len(tokens) = 4
```

### 5.2 重叠策略

```python
threshold = chunk_token_num * (100 - overlapped_percent) / 100

# 示例
chunk_token_num = 128
overlapped_percent = 20

threshold = 128 * 0.8 = 102.4

# 含义: 当前chunk达到102.4 tokens时，下一个section会新建chunk
# 新chunk会包含旧chunk的后20%作为前缀
```

**重叠的优势**:
```
无重叠:
chunk1: "...文本结尾"
chunk2: "新文本开头..."
        ↑ 丢失上下文

有重叠:
chunk1: "...文本结尾部分上下文"
chunk2: "结尾部分上下文新文本开头..."
        ↑ 保留上下文
```

### 5.3 位置标签保留

**位置标签格式**:
```
@@页码1-页码2-...	x0	x1	top	bottom##

示例:
@@1-3	100.0	500.0	800.0	50.5##

含义: 从第1页跨越到第3页，水平位置100-500，垂直位置800-50.5
```


### 5.4 短文本过滤

```python
if tnum < 8:
    pos = ""  # 移除位置标签
```

**设计原因**:
- Token数<8的文本通常是无意义的片段
- 不值得保留位置信息
- 避免索引过短的无效内容

**示例**:
```python
text = "的"  # 单字助词
tnum = 1 < 8
→ pos = ""  # 不保留位置标签

text = "人工智能技术的发展非常迅速，正在改变我们的生活方式。"
tnum = 25 > 8
→ pos = "@@1\t100\t500\t0\t200##"  # 保留位置标签
```

### 5.5 自定义分隔符解析

**正则表达式**: ``r`([^`]+)` ``

### 6.3 chunk_token_num的选择

**推荐值**:
```python
# 短文档（新闻、博客）
chunk_token_num = 128

# 中等文档（技术文档、报告）
chunk_token_num = 256

# 长文档（论文、书籍）
chunk_token_num = 512

# 超长文档（法律文件、规范）
chunk_token_num = 1024
```

**影响因素**:
- 向量模型的token限制（如OpenAI: 8191）
- 检索精度（chunk越小越精准）
- 上下文完整性（chunk越大上下文越完整）
- 查询类型（问答: 小chunk; 摘要: 大chunk）

## 七、边界情况处理

### 7.1 空输入

```python
sections = []
→ return []

sections = ""
→ 标准化为 [""]
→ return []
```

### 7.2 空sections

```python
sections = ["", "", ""]
→ 每个section通过 "\n" + sec = "\n"
→ tnum = 1 < 8
→ pos = ""
→ 但仍会添加到cks（除非是连续的空chunk）
```

### 7.3 单个超长section

```python
sections = ["这是一个非常长的section..." * 100]  # 假设1000 tokens
chunk_token_num = 128

处理:
section 0:
  tnum = 1000
  threshold = 128
  → 新建chunk: 包含整个1000 tokens的section

注意: 单个section不会被拆分，即使超过chunk_token_num
```

### 7.4 overlapped_percent = 100

```python
overlapped_percent = 100
threshold = chunk_token_num * 0 / 100 = 0

结果: 每个section都新建chunk，重叠100%（完全重复）
实际场景中不建议使用（会产生大量重复内容）
```

## 八、性能优化

### 8.1 Token计数缓存

```python
# 当前实现: 每次都重新计算
tnum = num_tokens_from_string(t)

# 优化方案: 缓存已计算的文本
token_cache = {}

def cached_num_tokens(text):
    if text not in token_cache:
        token_cache[text] = num_tokens_from_string(text)
    return token_cache[text]
```

### 8.2 预分配空间

```python
# 当前实现: 动态扩展列表
cks = [""]
tk_nums = [0]

# 优化方案: 预分配空间
estimated_chunks = len(sections) * 2  # 估算
cks = [None] * estimated_chunks
tk_nums = [0] * estimated_chunks
```

### 8.3 避免字符串拼接

```python
# 当前实现: 频繁字符串拼接
cks[-1] += t

# 优化方案: 使用列表收集，最后join
chunk_parts = []
chunk_parts.append(t)
final_chunk = "".join(chunk_parts)
```

## 九、总结

### 9.1 核心特性

1. **智能合并**: 按token数量自动合并sections
2. **重叠支持**: 通过overlapped_percent实现chunk间的重叠
3. **位置保留**: 保留PDF的位置标签信息
4. **自定义分隔**: 支持用户自定义的分隔符进行强制分割
5. **短文本过滤**: 过滤token<8的无效内容
6. **灵活输入**: 支持字符串、列表等多种输入格式

### 9.2 设计优势

- **简单高效**: 逻辑清晰，易于理解和维护
- **可控性强**: 通过参数精确控制chunk大小和重叠比例
- **上下文保持**: 重叠机制保证chunk间的上下文连续性
- **格式兼容**: 自动处理位置标签，兼容PDF解析流程

### 9.3 应用场景

- **PDF文档分块**: 将PDF解析的sections合并成合适大小的chunks
- **RAG检索**: 为向量检索准备合适粒度的文本块
- **文档索引**: 构建Elasticsearch/Infinity的文档索引
- **多模态处理**: 结合naive_merge_with_images处理带图像的文档

### 9.4 参数调优建议
